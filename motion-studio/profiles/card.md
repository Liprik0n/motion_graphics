# Профиль: открытка (ролик без голоса)

Короткий ролик под музыку без диктора: поздравительная открытка, заставка, анимированный титр, шорт без
речи. Читается на этапе 0 вместе с ядром; ниже — только отличия от ядра и от
[`edu-dialog.md`](edu-dialog.md). Профиль выведен из одной сданной открытки (35–45 с, пять сцен, один трек):
числа ниже — оттуда и помечены «замер одной открытки», на втором ролике их сверить и записать в `lessons.md`.

## Когда выбирать

Нет диктора и не будет; смысл несут кадр, движение и надпись; длина 15–60 с; время событий задаёт музыка.
Есть диктор или два голоса — [`edu-dialog.md`](edu-dialog.md), [`promo.md`](promo.md), [`explainer.md`](explainer.md).

## Откуда берётся шкала времени

Единственный источник времени ролика с голосом — звук реплик. Здесь его заменяет **шкала тактов музыки**:

1. Выбран трек (библиотека, лицензия — [`process/06-music.md`](../process/06-music.md)); темп и затакт замерены, такт
   в секундах записан числом.
2. Манифест фильма (`films/<фильм>.json "manifest"`) — список **немых строк**
   `{n, scene, voice, ms, scene_start, silent: true, what}`: по строке на такт или группу тактов; `ms` — длина,
   `scene_start` — начало на шкале своей сцены, `voice` — любое слово (голоса в `voices.json` нет и не нужен).
   Образец — `template/project/director/silent-timeline.json`.
3. Якорь события в раскадровке — `{reply: <n немой строки>, at, offset?}`: это **такт**, а не секунда. Сдвинулась шкала
   (`ms`, `scene_start`, `tail_sec`) — сдвинулись все события, ничего переписывать не надо.
4. У каждой сцены должна быть хотя бы одна строка шкалы; сцена без строк — отказ сборки с подсказкой. Озвученных
   реплик у сцены может не быть вовсе.

Ключи фильма: `"manifest"`, `"tail_sec"` (хвост после последней строки; у открытки 0 — затухание ведёт музыка),
`"voice_bars": false`; `"libs": [путь.js]` — скрипты проекта в `<head>` до разметки сцен (набор букв, общая механика);
`"stills": true` — кадры шва и детерминизма для промера пикселей набором.

## Звук без голоса

- `music.json`: `"without_voice": true` (любой фильм проекта) или `["<фильм>"]` (только названные; озвученный фильм
  рядом по-прежнему требует реплики с mp3). Музыка идёт на `track_lufs` без приглушения, затухание финала —
  `tail_fade_sec`; микс = музыка + эффекты, итог −16 LUFS / −1 dBTP как у ядра.
- Эффекты (`sfx.json`) ставятся **от действий сцены**, без реплики-якоря: события фильма `act` (метки
  `plugins.act` с исполнителем: `who`, `do`) и метки звука в раскадровке `plugins.act.cues[].sfx[]`
  `{name, t, role}` (`kind: "mark"`). Метка без правила и без имени в `silent_marks {имя: причина}` — ошибка сборки.
- Уровни `gain_db` — дБ относительно музыки рядом (окно ± `music_ref_pad_sec`); потолок сборки `over_music_target_db`,
  проверки `over_music_max_db`. `texture: true` — фактура вне правила плотности (акценты не ближе `min_gap_sec`),
  `shift_sec` — удар позже события.
- Клипы синтеза для таких звуков уже в `engine/audio/synth.py` (шорохи, колокольчики, «вжух», лампочка, перезвон) —
  новые добавляются туда же, без сети и абсолютных путей.
- Проба: `sfx.py <фильм>` собирает куски готового микса (музыка + эффекты) по одному звуку подряд.
- Команды: `music.py <фильм>`, затем `--mux` (после рендера); `check_mix.py <фильм> [--final]`. Условия про голос
  (M5, M9, M11 «под речью» и «в паузах») в отчёте помечены `--` как пропущенные, а не красные; их место занимает
  M11 «эффект ≤ `over_music_max_db` к музыке рядом».

## Проверки видео для ролика без голоса

V2 принимает немые строки; V17 («порядок появления = порядок речи») — пропуск «речи нет»; V36 (живость по зонам) и V37
(читаемость текста по пикселям) для открытки главные, но только со своими числами и объявленным текстом:

- **`density.max_static` — своё число для коротких сцен.** V36 краснеет, когда слой сначала двигался `max_static`, а
  потом стоял дольше него: при шаблонных 6,0 с и шаге промера 0,5 с сцена короче 12,5 с покраснеть не может, а пять
  сцен ролика в 35–45 с — это 7–9 с на сцену. Число ставит режиссёр в `tokens.json` так, чтобы два `max_static` и шаг
  `density.zones.step_sec` были короче самой короткой сцены: в пробе на сцене 8,73 с брали 2,0 (замер одной сцены).
  Сцены, которым порог велик, называет строка V36 («покраснеть не может: …»); если такова каждая сцена фильма,
  `--red` даёт MISS «ни одна сцена не может покраснеть» — это повод уменьшить число, а не признак живости. Законная
  пауза объявляется в раскадровке (`still`).
- **Текст на canvas V37 мерит только объявленным.** Набор букв (`libs/card-kit.js`) отдаёт области строк фразы сам,
  после сборки (`L.textRects`); любой другой текст на canvas сцена объявляет `window.__textRects(t)`. Необъявленный текст не измерен,
  и зелёная V37 о нём ничего не говорит: в пробе пунктир вместо сплошных букв прошёл зелёным и нашёлся глазом.

Таблица условий — `template/engine/video/CHECKS.md`.

## Особые риски

- **Событие на секунде, а не на такте.** Секундный якорь не переживает смену монтажа трека: все биты — через строки шкалы.
- **Сцена без шкалы.** Нет строки — нет времени; пустую сцену не «растягивают» на глаз.
- **Эффект громче музыки.** Уровни без голоса считаются от музыки, а не от речи: сначала собрать музыку, потом ставить
  `gain_db` (M11).
- **Тишина как дефект.** Между событиями без движения кадр «замирает» (V36); паузе нужна причина, а не авось.
- **Тексты открытки.** Короткий экранный текст не прощает лишнего: запреты своего ролика (обороты, цифры, подпись)
  пишутся в `project.json text_guard` (V34) до первой сцены, а не после показа.
