# Профиль: объяснялка

Ролик, где один диктор (или голос за кадром без персонажей) объясняет одну тему схемами и
метафорами: «как работает ...», «что делать, если ...». Ближайший к ядру профиль после учебного диалога.
Читается на этапе 0; ниже — только отличия от ядра и от [`edu-dialog.md`](edu-dialog.md). Профиль **не
проверен нами на практике**; числа — из внешних разборов, помечены «не калибровано».

## Что меняется относительно ядра

| Параметр | Ядро (учебный диалог) | Объяснялка |
|---|---|---|
| Длительность | 10–20 минут | одна глава 3–6 минут; дольше — главы с экраном-разделителем (Guo и др.); одна идея на сцену, ориентир сцены 15–30 с (внешний разбор, не калибровано) |
| Структура | диалог, роли реплик, сквозной мотив | одна идея на сцену; главная мысль ясна ко второй сцене; сквозной образ — схема, которая трансформируется (3Blue1Brown), а не смена сцен |
| Голос | два голоса, легенда персонажей | один голос, нейтральная эмоция по умолчанию; подбор — [`process/05-voice.md`](../process/05-voice.md) без легенды диалога, но с требованием «слушаемость на 5+ минутах» |
| Текст в кадре | ключевые слова, куски в паузах чтеца | не дублировать речь целыми фразами (избыточность, d ≈ 0,87 по сниппетам Майера); подсветка 1–3 ключевых слов в момент их произнесения |
| Движение | уровни 0,5 / 0,4 / 0,45 / 0,9, дыхание фокуса | базовая пара изинга и длительности из внешнего справочника: `power2.out`, 0,4–0,6 с, переходы 0,5–0,8 с, 3–5 типов переходов на фильм — не калибровано, сверить с числами режиссёра в `tokens.json` |
| Звук | музыка по главам, эффекты акцентами | то же, музыка чуть ближе к ритму схемы; плотность эффектов от метафоры |
| Фактчек | по регламенту: сроки, запреты | по источнику темы: числа и определения сверять с первоисточником; «в первоисточнике нет» — тоже ответ |
| Персонажи | ведущие выключены по решению пользователя | персонажи не нужны; правила рига (`process/02-design.md` «Лист облика героя») — справочник на случай включения |
| Роли | все | режиссёр + исполнитель + звукорежиссёр + QA + фактчекер; без диалогового редактора |
| Приёмы и стиль | пресеты 1–3 вставки | сильнее всего «скетчбук» (схемы на салфетке) и «стекло» (цифровая система): [`catalog/styles.md`](../catalog/styles.md); приёмы процесса и схем — по раскадровке ([`process/04-storyboard.md`](../process/04-storyboard.md)) |

## Что берётся как есть

Все этапы и ворота, пилот двух сцен, текст документа ≠ текст в синтез, линт и промер, музыка из
библиотеки с лицензией, независимый QA, лист кадров швов, свежесть артефактов, честные статусы.

## Особые риски

- **Один голос на 5 минут утомляет**: эмоцию меняют по смыслу сцены, а не по расписанию; промер
  протяжности (класс 10) работает так же.
- **«Красивая схема без смысла»**: каждый графический элемент объясняет шаг; элемент без опоры —
  класс 2.
- **Ориентиры насмотренности**: Kurzgesagt (длинная форма, метафоры, ритм речь ↔ картинка) и
  3Blue1Brown (одна трансформирующаяся схема) — не копируются, только приём
  ([`process/10-references.md`](../process/10-references.md); статус «по памяти»).
