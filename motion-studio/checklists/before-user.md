# Ворота перед показом пользователю

Читать оркестратору на этапе 10 — перед **каждым** показом: пилот, волна, версия фильма, файлы
прослушки. Ни один пункт не отменяется «ради скорости»: в прошлом ролике пользователь получил версию с
дефектом, который эти ворота ловят, дважды — ёлка «в пустоте» и резкость, потому что независимый
просмотр убрали ради экономии лимитов (класс 24, `../lessons.md` строка 37). Классы дефектов
— [`defect-classes.md`](defect-classes.md); этапы и ворота — `SKILL.md`.

Отметка «сделано» ставится с доказательством: путь файла, число условий, имя агента. Пункт без
доказательства не пройден.

## Ворота

### 1. Свежесть артефактов (класс 19)

- [ ] Каждый показываемый выход (`video.mp4`, `video-music.mp4`, `mix.m4a`, листы кадров, файлы
      прослушки) **не старше** своих входов: `rows.json`, `speech_edits.json`, `voices.json`,
      раскадровки, `tokens.json`, `music.json`, `sfx.json`, `film.json`.
- [ ] Звук пересобран после последней правки: `music.py <film> --mux` после любого сдвига `film.json`.
- [ ] Проверка: список входов новее выхода пуст (`process/08-render-qa.md` «Свежесть артефактов»).
- [ ] В отчёт записано время сборки выхода и дата последней правки входов.

### 2. Проверки машины

- [ ] `check.py <film>` (или `--page` для пилота): зелёный; число условий названо, оно **больше нуля**.
- [ ] `check_audio.py` зелёный, красные записаны в `speech_edits.json[N].allow` после прослушки.
- [ ] `check_mix.py` зелёный: −16 LUFS, пик ≤ −1 dBTP, голоса ≤ 0,5 дБ, эффекты на месте.
- [ ] `speech_lint.py` чист; `--red` и `--samples` этих проверок на момент показа прогонялись зелёными.
- [ ] Ни одна проверка не отключена и не ослаблена по ходу; если порог менялся — записано основание
      (класс 23 в [`defect-classes.md`](defect-classes.md)).

### 3. Лист кадров швов и просмотр глазами (классы 1, 2, 5, 15, 32–35)

- [ ] Лист кадров швов собран и **открыт** (каждый лист, не по списку); на каждом шве — первый и
      последний кадры и полоса ±0,5 с (`process/08-render-qa.md`).
- [ ] Отвечен вопрос листа: понятен ли каждый элемент зрителю без голоса?
- [ ] Закрытый список просмотрен (`templates/qa-brief.md`): телепорт · дёрганье · резкое появление ·
      повтор приёма · обрезка краем · мелкий текст · пустой кадр · текст на тексте · двойник ·
      элемент без опоры · спутник отстаёт · порядок экрана ≠ порядку речи · вспышки · расхождение с раскадровкой ·
      движение задом наперёд · жест или взгляд мимо цели · действие без следа · лишняя часть тела · дребезг на речи.
- [ ] Ключевые кадры пролога и финала сверены с листом, который принял пользователь (класс 21).
- [ ] Сцены с героем и швы между мирами открыты **в движении** (черновик `--draft`), пользователю
      уходит он, а не лист (классы 32–34; `process/08-render-qa.md` «Черновик в движении»).

### 4. Независимый QA (класс 24)

- [ ] Агент `motion-qa` со **свежим контекстом** вернул отчёт: три худших места, остальное по классам,
      «что смотрел», «не смотрел», вердикт. Вердикт «нельзя показывать» блокирует показ.
- [ ] Режиссёр принял кадры сцен против своих эскизов (отчёт «принято» или список расхождений).
- [ ] Оркестратор не ревьюит собственные задачи.

### 5. Прослушка (классы 7–12)

- [ ] Файлы для прослушки собраны (трудные слова из В9, реплики с красным промером, проба эффектов
      `sfx-proba.mp3`, пилот музыки).
- [ ] В сообщении названо, **что слушать**; «прослушай всё» не просьба.
- [ ] Статус «прослушано» ставится только если слушал человек; иначе «проверено числами».

### 6. Сверка «каждое позже стало строкой плана» (класс 20)

- [ ] Выписаны все «позже», «потом», «отдельным шагом» из слов пользователя и из интервью (В7 и др.).
- [ ] Каждое либо сделано, либо стоит строкой плана с датой; в отчёте — таблица «слова → состояние».
- [ ] Слова пользователя последнего отзыва — дословно: каждое стало задачей и закрыто или названо открытым.
      Утверждённое пользователем («keep») не тронуто.

### 7. Факты и права

- [ ] Отчёт фактчекера без открытых строк (квантор, порядок, открытость перечня), если менялся текст.
- [ ] У каждого трека и эффекта строка манифеста с лицензией (`process/06-music.md`); скачанные
      файлы — только с явным «да».
- [ ] Реквизиты в кадре (даты, телефоны, ФИО) — те, что пользователь разрешил (класс 18).

### 8. Безопасность и расход

- [ ] В отчётах, логах и сообщениях нет значений `.env`.
- [ ] Расход знаков синтеза: запрошено / израсходовано / лимит; платных вызовов без слова пользователя нет.

## Шаблон сообщения пользователю

Коротко, без лога: что показываем, что изменилось, статусы, вопрос.

```
ПОКАЗЫВАЮ: <файл или лист>, версия <метка>, собрано <время>.
ЧТО ИЗМЕНИЛОСЬ: <по твоим словам "...": строка → результат>.
СТАТУСЫ: собрано · проверено числами (N условий) · просмотрено по кадрам / не смотрел · в движении / не смотрел · прослушано / не слушал.
ПРОВЕРЬ ГЛАЗАМИ / УШАМИ: <места: момент {reply, at} или таймкод, что смотреть>.
ПОЗЖЕ: <список отложенного с датой>.
ВОПРОС: <один вопрос, варианты, первый «(Рекомендую)»>.
```

## После ответа пользователя

Каждый отзыв — на этап 11: найти место по кадру и времени, назвать класс дефекта, дописать строку в
[`lessons.md`](../lessons.md) и класс в [`defect-classes.md`](defect-classes.md), завести условие с
порчей, если класс меряется. Правило без места, где оно закреплено, потеряется к следующему ролику.
