# Плагины движка и признаки сцены — `engine/video/plugins/<имя>.js`

Плагин включает сцена: поле раскадровки `"plugins": {"<имя>": {...}}`. Сборка (`build.py`) сама подключает
`plugins/<имя>.js`, переводит каждое значение-момент `{reply, at, offset}` в секунды фильма и кладёт настройки в
`FILM.scenes[i].plugins.<имя>`. Недостающие поля берутся из `tokens.json motion.<имя>` (числа движения утверждает
режиссёр), поверх — `films/<фильм>.json "plugin_config": {"<имя>": {...}}` (вариант фильма). Обязательного поля нет
нигде — отказ сборки с его именем: запасных чисел в коде нет.

Кадр — чистая функция времени (закон 1): случайность только от зерна и номера кадра, ни `Math.random`, ни `Date`, ни
памяти прошлого кадра. Свои плагины проекта (не движка) подключает фильм: `films/<фильм>.json "plugins": ["<путь от
корня проекта>.js"]`.

Фикстуры — фильмы `films/bare.json` (сцены `bare-start`, `bare-timer`), `films/acts.json` (`act-stage`, `act-sign`),
`films/acts-hide.json`; порчи — `checks/red_bare.py`, `checks/red_acts.py`; условия — `CHECKS.md`, V26–V35.

## Признаки сцены и фильма (поля, не плагины)

| Поле | Где | Что делает | Проверка |
|---|---|---|---|
| `"frame": false` | раскадровка | сцена без каркаса учебного жанра: нет заголовка, номера, трекера, линий, футера, полосок голоса. С ним нельзя `title_at`, `num_at`, `chapter_at`, `chapter_from`, `tracker_emph` (отказ сборки). На стыке со сценой с каркасом общая часть каркаса (`#frame-global`) наплывает за ± `frame.seam_half`; все сцены фильма без каркаса — каркаса на странице нет вовсе. Наборы стилей читают признак (`FILM.scenes[i].frame`) | V26 |
| `"start_image": "<путь>.png"` | раскадровка | сцена начинается с картинки-кадра (PNG размером с полотно, путь от корня проекта): сборка кладёт элемент `start-image` (слой under, во всё полотно, виден с первого кадра на 1,0). Биты могут его двигать, приглушать, убирать; без битов он уходит вместе с содержанием сцены после её последней реплики. Стык с готовым роликом: последний кадр того ролика — первая картинка этого | V28; пиксели — `tests/test_start_frame.py` |
| `"hide": ["id" \| "сцена:id", …]` | фильм | элемент на странице есть, но не виден ни в одном кадре; биты на него снимаются (сборка и проверка — одинаково). Вариант ролика (без даты, без отсчёта) без копии сцены. Неизвестный id — отказ сборки | V33 |
| `{n, scene, voice, ms, silent: true, what}` | строка звука фильма | немая строка — опора времени для действия без речи: файла нет, длина — `ms`, рот закрыт (огибающая — нули), полоски голоса и подпись голоса в покое, в сведении молчит (`engine/audio` берёт только строки с файлом). `silent` с файлом или без `ms` — отказ сборки. Якорь `{reply: <n немой строки>, at}` работает как у обычной реплики | V2 |
| `"timeline_offset_sec"` | фильм | где кусок стоит в склейке (секунд от её начала): таймер и часы считают настенное время кадра от него | V29, V30 |
| `"fonts": [{role, family, files, descriptors?, note?}]` | `project.json` | роли шрифтов проекта сверх `tokens.json fonts` (там — фирменный `brand`): цифры табло, заголовочный, рукописный. Каждая роль даёт `--font-<роль>` (запасной — фирменный); `descriptors` — `ascent-override`, `descent-override`, `line-gap-override`, `size-adjust` в `@font-face`. Роль одна на оба файла (повтор — отказ), роль без файла — отказ. Плагины ссылаются на роль (`digits_font`, `font`) | V11 |
| `"legibility_except": [{el: "сцена:id", max_opacity, min_visible, min_visible_sec, why}]` | `project.json` | намеренно тусклая надпись (вывеска, водяной знак): элемент не мерится V21 (контраст в стиле) и правилом «в итоге сцены всё на 1,0» V9; взамен V35 — не ярче `max_opacity`, видна дольше `min_visible_sec`. Только названный элемент | V35 |
| `"text_guard": {"rules": [{name, re, scenes?, els?, except?}]}` | `project.json` | сторож текста проекта: запреты своего ролика (старое название, имя, которого не должно быть в кадре, время цифрами там, где его считает плагин) — по тексту кадра и по разметке и текстам раскадровки сцен фильма | V34 |
| `"wall_clock": {start, lead_sec, event}` | `project.json` | настенное время ролика (`engine/video/wallclock.py`): `start` — когда ролик начинают смотреть (ISO 8601, пояс обязателен), `lead_sec` — сколько секунд идёт до первого кадра склейки (0 — ролик первый), `event` — момент события для таймера. Нужно только плагинам `timer` и `clock` | V29, V30 |

## act — действия мира и камера сцены

Метки раскадровки `"plugins": {"act": {"cues": [{id, t, who, do, motion?, …, note?}]}}`: `id` — уникален в сцене,
`t` — момент `{reply, at, offset}`, `who` — кто действует (id элемента сцены, `cam` — камера, `world` — мир стиля),
`do` — что делает (любое слово: его понимает исполнитель), `motion` — имя строки `tokens.json motion.act` (неизвестное —
отказ сборки), остальные поля (`to`, `from`, `pose`, `target`, `count`…) — исполнителю как есть, `note` — для людей.
Сборка кладёт в метку `m` — числа `motion.act.<motion>` и `span` — длину действия: `dur`, иначе `in + hold + out`,
иначе `spinup`, `roll`, `min`, иначе 0 (мгновенная смена). Своих чисел у плагина нет.

**Исполнитель** — тот, кто рисует мир (разметка сцены, плагин стиля, марионетка, спрайт):

```js
(window.ActExec = window.ActExec || []).push({scene: '<сцена>', who: '<id>', run: function (t, cues, api) {
  // cues — метки этого who по времени: {cue, local: t − cue.t, p: 0…1 за span, e: p по кривой m.ease}
  // состояние в момент t — по всем меткам сразу (кадр — чистая функция t); меняется ВНУТРЕННОСТЬ узла who
}, node: необязательный узел, чьё изменение мерить (если who — не элемент сцены, например world)});
```

Непрозрачность и трансформацию самого `.el` ведут биты — исполнитель их не трогает (закон 2). Регистрация — до первого
кадра (скрипт в разметке сцены, плагин стиля). Метка без исполнителя сборку не роняет, но краснеет V31. Мир стиля берёт
время у тех же меток: набор стиля отдаёт их сцене как `kit.cues(сцена)` (рядом с `kit.at`, `styles/README.md`).

**Камера** (`who: "cam"`, исполняет движок): `do: "move"`, `to` — положение, `from` — откуда (у первой метки; иначе
камера стоит на всём кадре), `motion` обязателен (строка `motion.act` с `dur` и `ease`). Положения — узлы разметки сцены
`<div class="cam-pos" data-cam="<имя>" style="left:…px;top:…px;width:…px;height:…px"></div>`: рамка мира, которую
камера растягивает на весь кадр (пропорции кадра ± 1 %; нет положения — отказ сборки). Содержание сцены со своей камерой
лежит в трёх обёртках `#cam--<сцена> > .cam-float > .cam-shake` (закон 4): сюжетное движение; парение
(`motion.act.cam_drift`: `pct` — размах в % кадра, `period` — период, с; без `period` парения нет); толчок — у любой
метки, чьё `motion` несёт `shake_px` и `shake_dur` (удар, хлопок). Картинка-кадр `start-image` — снаружи камеры.

Промер: у каждой метки — время, есть ли исполнитель, отпечаток узла `who` около метки; у камеры — рамка мира и
парение. Проверки — V31 (метка исполнена), V32 (камера доехала, парение ≤ порога, обёртки не `.el`), V3 (в сцене с
камерой целиком в кадре — строки надписей, а не рамки: мир больше кадра).

## glitch — помехи

Рвёт картинку элемента-источника (по умолчанию `start-image`): полосы кадра сдвигаются вбок, красный и синий каналы
расходятся, кадр дрожит. Холст ложится сразу над источником и берёт его трансформацию и непрозрачность.

| Поле | Тип | Что |
|---|---|---|
| `from`, `to` | момент | окно помех |
| `seed` | целое | зерно: расписание вспышек и рисунок кадра |
| `source` | id | элемент с картинкой (`<img>`); умолчание `start-image` |
| `tear_px` | px | наибольший сдвиг полосы при силе 1 |
| `bands` | [мин, макс] | число полос при силе 1 |
| `band_h` | [мин, макс] px | высота полосы |
| `rgb_px` | px | расхождение каналов при силе 1 |
| `jitter_px` | px | дрожь кадра при силе 1 |
| `burst_gap` | [мин, макс] с | промежуток между началами вспышек (держит частоту) |
| `burst_frames` | [мин, макс] | длина вспышки в кадрах |
| `calm` | 0…1 | сила между вспышками |
| `edge` | с | рампа силы на краях окна |

Промер — `probe_frames.mjs` (каждый кадр окна ± 0,5 с в 1/10 размера, три кадра дважды в разном порядке после
перезагрузки; сборка зовёт его сама, под замком Chrome); проверка — V27: вспышек не больше
`tokens.json legibility.flash_max_per_sec` в секунду (WCAG 2.3.1), помехи видны, кадр детерминирован.

## timer — отсчёт до события

Рисует внутри элемента-хозяина четыре группы «число над подписью» с разделителями; подписи — надписи `.t` (их видят
V4, V10, V18), числа — нет. Видимость, вход и уход — у хозяина, битами сцены.

| Поле | Тип | Что |
|---|---|---|
| `host` | id | элемент сцены, внутри которого таймер |
| `at` | момент | с этого момента отсчёт идёт по кадрам; значение в нём — `wallclock.timer_at(wall_clock.start, wall_clock.lead_sec, timeline_offset_sec + at, wall_clock.event)` |
| `mode` | `countdown` \| `date` | `date` — вместо отсчёта строка `date_text` (вариант ролика без отсчёта) |
| `digits_px`, `labels_px`, `gap_px`, `label_gap_px` | px | кегль чисел, подписей, зазор между группами, зазор число–подпись |
| `digits_color`, `labels_color` | роль палитры | цвет чисел и подписей |
| `digits_font`, `labels_font` | роль шрифта | `role` из `tokens.json fonts` или `project.json fonts` |
| `labels` | 4 строки | подписи дней, часов, минут, секунд — язык ролика, из раскадровки или `tokens.json motion.timer` |
| `sep` | строка | разделитель групп |

Проверка — V29: в момент `at` и дальше по кадрам таймер показывает то, что следует из `project.json wall_clock` и
смещения куска; секунды идут вниз; подписи — те. Сдвинулся старт — правится только `wall_clock.start`, пересобирается
кусок с таймером и склейка (отметка кадров куска устаревает сама: в `film.json` лежит посчитанное значение).

## clock — часы в кадре

`"plugins": {"clock": {"host": "<id>"}}`, остальное — `tokens.json motion.clock`: `mode` (`digital`), `format`
(`HH:MM:SS` | `HH:MM`), `digits_px`, `color` (роль палитры), `font` (роль шрифта). Табло в секунду t куска =
`wall_clock.start + wall_clock.lead_sec + timeline_offset_sec + t` в поясе `start` (`wallclock.clock_at`), секунды
вниз, через полночь — по кругу. Цифры — не надпись `.t` (их считает сборка); вписать цифры в хозяина руками — провал
V30 (и сторожа текста V34, если проект завёл правило). Проверка — V30 (считает сама, не из сборки).
