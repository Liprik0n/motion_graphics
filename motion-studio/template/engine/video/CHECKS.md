# Проверка ролика — `engine/video/check.py`

Ядро условий, общее для любого фильма. Проверка читает только диск: `film.json`, `probe.json`,
`index.html`, `video.mp4` и mp3 реплик (промер ffmpeg), раскадровки и разметку сцен, конфиги проекта
(`project.json`, `tokens.json`, `films/<фильм>.json`, `rows.json`, `text/`). Сборку не импортирует.
Пороги, которые задаёт проект, — из конфигов; пороги самой проверки — константы в начале `check.py`,
замеренные на принятом ролике.

## Команды

```
python engine/video/check.py demo --page                 страница без рендера: код 0 / 1, построчный отчёт
python engine/video/check.py demo                        ролик целиком: + video.mp4 (V1 мерит видео и звук и
                                                         сверяет ролик со страницей: отметка кадров не устарела)
python engine/video/check.py film --only a,b --page      пара сцен, шов без рендера
python engine/video/check.py demo --red [подстрока]      быстрые порчи: 86, ≈ 1,5 мин
python engine/video/check.py demo --samples [подстрока]  образцы: 19, молча, ≈ 30 с
python engine/video/check.py demo --red-slow [подстрока] медленные: 14 порч + 4 образца, ≈ 2,5 мин
python engine/video/check.py <фильм> --red-init          завести порчи своего фильма: checks/red_<фильм>.py
  --project DIR   корень проекта (иначе MOTION_PROJECT, иначе <шаблон>/project)
  --out-dir DIR   страница собрана не в <out>/<фильм>
```

Строка отчёта — `OK`, `FAIL` или `SKIP`. `SKIP` бывает у V4 (у проекта нет папки `paths.text`, сверять
не с чем), у V21–V24 (у фильма нет стиля), у V25 (в фильме нет размеченных конечностей героя) и у V26–V35 (в фильме
нет того, что они мерят: сцены без каркаса, помех, картинки-кадра, таймера, часов, меток act, камеры, ключа `hide`,
сторожа текста, тусклой вывески — строка `SKIP` называет, чего нет), у V36 и V37 («нечего мерить»: ни одного
движущегося слоя, ни одной строки текста на 1,0) и у V38–V43 (в фильме нет букв пером, Lottie, набора букв, ключа
`stills`, долей трека). Код выхода от `SKIP` не меняется.

V36 и V37 смотрят кадры страницы, а не её числа: при первом запуске на странице `check.py` сам снимает полосу кадров
(`engine/tools/strip.py`, Chrome под общим замком — ожидание замка не зависание) и области текста
(`checks/probe_text.mjs`) в `<out>/<фильм>/strips/_cache/`; повторный запуск на той же странице Chrome не зовёт.
«Та же страница» — отпечаток `stamp.page_print`: `index.html`, `film.json` и каждый файл `assets/` — картинка-кадр или
шрифт, заменённые под тем же именем, страницу не меняют, а кадр меняют, и кадры снимаются заново.
На демо (21,6 с, 43 кадра) первый запуск дольше на ≈ 15 с (съёмка 13 с), повторный — на ≈ 2 с (V36 — 1,2 с, V37 — 0,9 с).

Фильм с проходами по стилям (`films/<f>.json "styles"`, см. `styles/README.md`):

```
python engine/video/check.py styles [--page]              все проходы <out>/styles/<стиль>/, итог по всем
python engine/video/check.py styles/film --page           один проход
python engine/video/check.py styles --red [подстрока]     24 порчи V21–V24, мир и замок (checks/red_styles.py), ≈ 6 мин
python engine/video/check.py styles --samples [подстрока] 11 образцов, ≈ 8 мин
python engine/video/check.py styles --red-slow            16 порч реестра стилей + 2 образца (свой стиль со всем движением: сборка + check.py), ≈ 1,5 мин
```

Порчи фильма берутся из `checks/red_<фильм>.py`, если такой файл есть, иначе — демо (`red_demo.py`). Фикстуры
возможностей движка — `bare` (`red_bare.py`) и `acts` (`red_acts.py`), раздел «Возможности движка» ниже.

Сборку для порч и любые пересборки делать **на копии проекта**: `build.py` пишет `schema.json`
и `cache/lipsync` в `<проект>/out/` даже при `--out-dir`. Медленные порчи сами копируют проект
во временную папку (без `out/`, `node_modules`, `.env`) и удаляют её.

## Возможности движка: без каркаса, помехи, картинка-кадр, таймер, часы, действия мира, камера, hide, сторож текста, тусклая вывеска (V26–V35)

Плагины и поля — `plugins/README.md`. Фикстуры — фильмы `films/bare.json` (сцены `bare-start`, `bare-timer`, обе
`frame: false`), `films/acts.json` (`act-stage` с каркасом: часы, метки act, камера, толчок, немая строка 901 →
`act-sign` без каркаса: тусклая вывеска) и `films/acts-hide.json` (`act-sign`, `hide: [head, when]`). Числа фикстур —
`tokens.json motion.glitch|timer|clock|act`, `project.json wall_clock|fonts|legibility_except|text_guard`.

```
python engine/video/build.py bare --page                  страница, промер DOM, промер помех (probe_frames.mjs)
python engine/video/check.py bare --page                  V1–V35
python engine/video/check.py bare --red                   27 порч, ≈ 30 с: V26–V29, V11 роли шрифта, ядро на фильме без каркаса
python engine/video/check.py bare --samples               3 образца
python engine/video/check.py bare --red-slow              8 порч + 1 образец: копия проекта, правка, build.py --page, ≈ 1 мин
python engine/video/build.py acts --page && python engine/video/build.py acts-hide --page
python engine/video/check.py acts --page                  V1–V35
python engine/video/check.py acts --red                   36 порч, ≈ 25 с (страницу acts-hide собирают сами, если её нет)
python engine/video/check.py acts --samples               7 образцов
python engine/video/check.py acts --red-slow              7 порч + 2 образца, ≈ 30 с
python engine/video/tests/test_wallclock.py               настенное время: 13 ожиданий, посчитанных руками (секунда)
python engine/video/tests/test_start_frame.py             первый кадр рендера = картинка-кадр пиксель в пиксель (≈ 1 мин)
```

`tokens.json fonts` + `project.json fonts` (2 быстрые порчи, 2 медленные: повтор роли, нет файла), синтез начертаний
при странице без каркаса — по корню (`probe.json rootStyle`); ключ `hide` снимает биты со скрытых элементов и в
проверке (`storyboards`), как в сборке. Схема раскадровки (`storyboard.py --red`) — порчи `frame` не да/нет,
`start_image` не PNG, плагин не объектом.

Сцена-проба наборов `kit-probe` (`films/kits.json`) играет жест манекена метками act («go», «wave») — исполнитель в
разметке, мир каждого набора стиля берёт время у тех же меток (`kit.cues`); V25 и V31 на ней зелёные во всех семи
проходах.

**Чего в возможностях нет и почему.** Пиксельных проверок миров стилей с героями (свой цвет кадра-стыка, игровое
окно пикселя), раскладки немых опор по монтажному листу и отметки кадров по входам таймера в шаблоне нет: миры
стилей шаблона без героев и надписей, раскладку немых строк пишет проект (`scene_start` в манифесте озвучки),
отметка кадров — отпечаток страницы (`stamp.py`), она ловит и смену `wall_clock`. Правила сторожа текста (имена,
даты и коды своего ролика) — данные проекта, а не движка.

## Глаз: живость по зонам и читаемость по пикселям (V36–V37)

То, что в открытке находил заказчик, а проверки не видели (ретро открытки, раздел B): слой стоит, буквы тонут в
фоне. Обе проверки мерят пиксели кадров страницы — кадры через `tokens.json density.zones.step_sec` секунд в полный
размер (`strip.frames`), области текста — `checks/probe_text.mjs`. Все пороги — в `tokens.json`; в `check.py` только
устройство промера (`EYE_*`).

| Шаблон | Что проверяет | Откуда | Порчи (быстрые · медленные) / образцы |
|---|---|---|---|
| V36 живость по зонам | кадр режется сеткой `density.zones.grid` [столбцов, строк]; зона сдвинулась между соседними кадрами, если яркость сменилась больше чем на `delta` у доли пикселей ≥ `min_share`. Зона, которая двигалась без остановки ≥ `density.max_static` с, — движущийся слой: после этого стоять внутри сцены дольше `max_static` ей нельзя. **Законная пауза** — поле раскадровки `still`: `{"from": {"reply": N, "at": 0…1, "offset": с}, "to": {…}, "why": "зачем кадр
стоит"}` (или список таких объектов). Моменты — якоря, как у битов; `why` обязателен (`storyboard.py`). Пары кадров
внутри паузы простоем не считаются; сборка поле не читает.

**Текст на canvas.** Надпись мимо DOM проверка сама не найдёт — сцена объявляет её области: `window.__textRects(t)` →
`[{id, rect: [x, y, w, h], text, opacity}]`, рамка каждой строки плотно по буквам в px кадра, `t` — секунды фильма,
`opacity` — насколько строка видна (мерится только на 1,0; без поля — 1). Два пути, они складываются
(`lib/stage.js`): сцена пишет `window.__textRects = function (t) {…}` в своём `<script>` разметки, либо плагин сцены
(`window.StagePlugins`) отдаёт метод `textRects(t)`. Так объявляют свои строки буквы «пером» (`plugins/pen.js`) и
набор букв (`libs/card-kit.js`, `L.textRects`: строка фразы — после сборки, пока слово не осыпается, в ней не открыты
окна и не начался нырок) — сцене с ними писать функцию не надо. Образец сцены — `DUSK_JS` в `checks/red_demo.py`.
Область, которая не объект с четырьмя числами, — провал V37 с именем `__textRects`.

**Порчи рисуются кодом** (`checks/red_film.py`), поверх кадров самого фильма, картинок в шаблоне нет: «слой заморожен»
— плашка на зону и предмет, который ехал `max_static` и встал. Порог — число проекта, порча его не трогает: в фильме,
где ни одна сцена не вмещает и движение, и простой, она не покраснеет — прогон пишет `MISS` с длиной самой длинной
сцены и порогом (V36 в таком фильме слепа, и зелёной порчей это не закрывается), образец паузы — `SKIP`. У демо шаблона
так: сцены 12,4 и 9,2 с при пороге 6,0 с — порчи V36 в списке демо нет, строка V36 на демо называет обе сцены; порча и
образец паузы идут на фильме `pen` (сцена 13,4 с). «Золото на закате» — светлые буквы (255, 214, 120) на шафране заката, в рамке надписи DOM и в объявленной
области canvas. Образцы: тот же замерший слой с паузой `still`; слой, который едет всю сцену; светлая заливка
(255, 244, 214) с тёмной обводкой (44, 22, 40) вплотную на том же закате — принятая обводка фразы вечера. Медленные —
настоящий canvas в `demo-b` со своей `__textRects`: светлое по светлому краснеет, обводка проходит.

**Свой фильм.** `check.py <фильм> --red-init` заводит `checks/red_<фильм>.py`: в нём этот минимум (порчи V36 и V37
годны для любого фильма) и списки для своих порч; существующий файл не трогается. Без своего файла `--red` и
`--samples` идут по тому же минимуму (`red_film.py`), а не отказываются.

## Чего в ядре нет и почему

- **Перекрытие с ведущими, поведение полосок голоса** — ведущих в кадре в шаблоне нет; полоски голоса есть,
  но их поведение в ядро не входит. Добавлять вместе с функцией.
- **Контракт видов, глава без двоения трекера, вспышка** — параметризуемые; в демо нет копии трекера и вспышки,
  калибровать не на чем.
- **Тематические проверки** (сезонный фон, свой каркас, шапка-история, пролог) живут рядом со своим плагином,
  не в ядре; как подключить плагин — `plugins/README.md`.
- **Смена фона** — в ядре нет слоя фона, который меняется; фон — `paper` палитры.

## Порчи и образцы

Данные — `engine/video/checks/red_demo.py`, калиброваны на демо-фильме шаблона целиком
(`films/demo.json`, сцены `demo-a`, `demo-b`). У другого фильма — свой файл `checks/red_<фильм>.py`
(его заводит `check.py <фильм> --red-init`); пока файла нет, `--red` и `--samples` идут по общему минимуму
`checks/red_film.py` — порчам глаза V36 и V37, годным для любого фильма.

- Порча — кортеж `(имя, порча, подстрока)`; засчитана, только если покраснела строка именно с
  этой подстрокой. Перед порчами исходный фильм обязан быть зелёным. Прогон — один на все файлы порч:
  `checks/redrun.py` (исходный фильм, цикл, вердикт `RED` / `MISS`, итоговая строка); файл порч держит списки и сами порчи.
- Порча, которую на этом фильме не построить, потому что проверка на нём слепа (`redrun.Unfit`), — `MISS` с причиной,
  а не пропуск: порог проекта ради порчи не меняется. Образец в таком фильме — `SKIP`.
- **Быстрые** (`--red`) — правка `probe.json` / `film.json` / конфигов в памяти, копии сцен без
  пересборки, временного корня для сторожа. Укладываются в 2 минуты.
- **Медленные** (`--red-slow`) — виды: `scenes` (копия проекта, правка раскадровки или разметки,
  `build.py --page` на копии), `project` (правка `rows.json`, `text/`, разметки без пересборки),
  `page` (правка копии страницы и новый промер `probe_dom.mjs`), `video` (копия `video.mp4`,
  обрезанная ffmpeg; только если ролик отрендерен — иначе строка `SKIP`).
- **Образцы** — законные варианты на грани порога: предмет без опоры 0,8 с, подмена со сдвигом
  0,6 px, 25 слов одним куском и 40 слов кусками, похожие законные слова для сторожа, уход под
  движением, провал непрозрачности до 0,5. Обязаны пройти молча.
- Литералы тематики в `red_demo.py` записаны `\u`-кодами: сторож сканирует и его.

## Оговорки

- V36 в сцене короче двух порогов `density.max_static` слепа: зона не успевает и ехать `max_static`, и простоять
  дольше него (при 6,0 с и кадрах через 0,5 с — сцены до 12,5 с). Строка отчёта называет такие сцены; в них живость
  остаётся вопросом полосы кадров и ревью. Проект с короткими сценами ставит свой `max_static`.
- V36 видит слой только по пикселям: зона, которая с первого кадра сцены не двигалась вовсе, от неподвижной по
  замыслу не отличима — «нечего мерить». Движение мельче `delta` и реже шага `step_sec` (мигание раз в несколько
  секунд) слоем не считается. Цепочка событий в одной зоне дольше `max_static` без перерыва — тоже «слой»: если после
  неё зона по замыслу стоит, это объявляет `still`.
- V37 меряет контраст в клетке, а не буквы: на пёстром фоне (фото, лампочки) клетка может набрать контраст за счёт
  фона, а не букв, — такой текст остаётся вопросом ревью «читается ли без усилия». Строки ниже 10 px в кадре,
  надписи не на 1,0 (тени уровня, наплыв) и каркас кроме заголовка (футер, трекер, подписи голоса) не мерятся.
  Порог шаблона `contrast_min` 2,4 ниже нормы WCAG 3,0: акцент палитры шаблона на бледной плашке даёт 2,56;
  проект со своей палитрой ставит 3,0.

- V17 лексический: пункт «назван», если две первые значимые основы его надписи (слова от 4 букв,
  основа — первые `max(4, длина − 2)` букв) стоят в речи подряд. Пункт, названный другими словами,
  проверка не видит — это остаётся вопросом режиссёра «понятен ли порядок без голоса».
- V15 опора — геометрия: касание рамки предмета с видимой надписью, заливкой или линией каркаса.
  Смысла («стоит ли предмет на своём») проверка не понимает; вопрос ревью — «понятен ли элемент без голоса».
- V20 видит «за один кадр» только там, где промер кадров подряд: паузы стыков и края событий
  (`probe_times`). Внутри сцены между событиями сетка 0,5 с.
- V4 на демо — `SKIP`: текст на экране демо нейтральный, источника нет.
