# Стили — модель «стиль — целый мир» и как сделать новый стиль

Стиль — именованный пресет, который **владеет миром кадра**: фоном, своей палитрой декора, шрифтом
заголовка, набором нарисованных кодом предметов, характером движения и материалом звука. Например:
скетчбук — тетрадный лист с карандашными рисунками, плёнка — тёмный зал, кадр-окно и ракорд с отсчётом.
**Бренд остаётся**: основной текст — фирменным шрифтом и ролями палитры бренда, переменные `--c-*`
не меняются, текст читается (V21).
Какие стили брать для учебного ролика — `../../../../catalog/styles.md`; здесь — механизм.

Образцы: `sketchbook/` (мир-рисунок) и `film/` (мир-слой). Общий код — `_core/` (`core.js` —
`window.StyleCore`, `registry.py`, `probe_style.mjs`).

## Что стиль обязан дать

| Что | Где | Проверяется |
|---|---|---|
| **фон кадра** — свой мир под каркасом и содержанием (лист, зал, небо, ткань…) | `plugin.js`, слой `back` | глазами: лист стилей |
| **палитра декора** — свои цвета мира, роли латиницей | `style.json decor` | реестр (hex); V22: цвета узлов ⊂ бренд ∪ decor |
| **шрифт заголовка** с кириллицей — файл: шрифт движка под OFL (`../assets/fonts/README.md`) или файл проекта | `style.json fonts.title` + `world.css` | реестр (кириллица — рендер букв); V22: загружен, и только он; V10: строка в рамке заголовка |
| **≥ 5 предметов мира**, нарисованных кодом (облака, солнце, ракорд, бобина, скотч, картуш…) | `style.json objects` + `plugin.js` | реестр (≥ 5 имён); глазами |
| **движение** — ступени «на N», перелёт, кипение, свои анимации предметов | `style.json motion` + `plugin.js` | V14, V24; глазами |
| **звук** — материал SFX | `style.json sfx.clips` | реестр (поля и границы) |

Чего стиль не трогает никогда: переменные `--c-*` (палитра бренда в `tokens.json`); цвет текста — только
роли бренда; шрифт, жирность и начертание основного текста; раскладку, координаты и время событий
содержания; геометрию каркаса (кегль заголовка — можно, если строка остаётся в рамке, V10).

## Стиль — это папка

```
engine/video/styles/<name>/        общий стиль движка
<проект>/styles/<name>/            свой стиль проекта (закрывает одноимённый стиль движка)
  style.json    обязателен: имя, подпись, decor, fonts, objects, params, motion, sfx
  style.css     необязателен: то, что годится и под замком бренда (фактура, обводка)
  world.css     необязателен: мир — шрифт заголовка и прочее, что не кладётся под замком
  plugin.js     необязателен на деле — без него мира нет: фон, предметы, фактуры, движение
```

Регистрации нет: стиль виден, как только появилась папка с `style.json` (`_core/registry.py names()`);
`build.py`, `check.py`, `storyboard.py` и схема не правятся — enum `style` собирается из папок.
Папки на `_` — общий код, не стили. Имя `none` занято: «без стиля».

## Где выбирается стиль и режим

Стиль сцены, сильнейший первым: `storyboard.json "style"` (`null`/`"none"` — без стиля) → проход фильма
(`films/<f>.json "styles": [...]` или `build.py <f> --style <имя>`) → `films/<f>.json "style"` →
`project.json "style"` → без стиля. Разные стили в одном фильме можно: `<section data-style>` у сцены,
`#root[data-style]` — стиль текущей сцены, мир перетекает на стыке за `frame.seam_half` (`api.styleWeight`).

Режим: **мир** по умолчанию. `project.json "style_brand_lock": true` — **замок бренда**, «только фактура»:
`world.css` не кладётся, плагин получает `cfg.world === false` и рисует фактуру поверх фирменного фона,
V22 строгий (любой цвет и шрифт узла со стилем = без стиля). Плагин обязан уметь оба режима.

Место под мир — `storyboard.json "decor_zones": [{x, y, w, h}]` (дюймы): пустые зоны сцены, куда стиль
кладёт предметы (`StyleCore.slots`). Без зон стиль рисует мир только по полям кадра. Режиссёр оставляет
зоны в раскадровке сцены, которой назначен стиль.

## style.json

| Поле | Обязательно | Что |
|---|---|---|
| `name`, `label` | да | = имя папки (латиница, цифры, дефис); подпись для людей |
| `decor` | да | `{роль: "#RRGGBB"}` — палитра мира; в плагине `cfg.decor.<роль>` |
| `fonts.title` | да | `{family, files: [имя файла…], weight?, note?}` — первый найденный файл (папка стиля → `<проект>/assets/fonts` → шрифты движка `engine/video/assets/fonts` → системная папка шрифтов); без кириллицы — отказ; не найден ни один — заголовок фирменным (строка в журнале сборки). Вариативный файл берётся целиком, вес задаёт `weight`. Или `{"kind": "code"}` — заголовок рисует плагин (см. «Заголовок кодом») |
| `fonts.decor` | нет | то же для надписей предметов (кромка плёнки, подписи на полях) |
| `fonts.<своя роль>` | нет | то же для своих надписей плагина (вырезки зина: `cut_poster`, `cut_serif`…); имя — латиница, цифры, `_`; в плагине `cfg.fonts.<роль>`, для холста — `StyleCore.fontOf('<name>', '<роль>')` |
| `objects` | да | ≥ 5 имён предметов мира — по ним `plugin.js` рисует в зоны (порядок = порядок раскладки) |
| `motion` | да | движение стиля — таблица «Движение» ниже |
| `sfx.clips.<вид>` | да (можно `{}`) | материал звука — таблица «Звук» ниже; вид — из `engine/audio/synth.py CLIPS` |
| `params` | нет | свободные числа плагина: `cfg.params` |
| `description`, `use_for`, `never` | нет | для людей |

Шрифты стиля сборка кладёт в `<out>/assets/fonts/sty-<name>-<роль>.*` и объявляет CSS-переменные
`--sty-<name>-title`, `--sty-<name>-decor`, `--sty-<name>-<своя роль>` (в плагине — `cfg.fonts.<роль>`, значение
вида `var(--sty-…)`: ставить в `el.style.fontFamily`, не в атрибут SVG).

**Шрифты стилей движка — файлы под OFL** в `engine/video/assets/fonts/` (семейство, источник, размер, лицензия —
`../assets/fonts/README.md`): кадр одинаков на любой машине, шаблон можно переносить и публиковать. Системный
шрифт (последнее место поиска) годится только своему стилю проекта: он не переносится на другую машину и не
публикуется, на машине без него заголовок останется фирменным. Стили движка системных шрифтов по имени не
называют — ни в `style.json`, ни в `plugin.js`.

## Движение (`style.json motion`, исполняет `lib/stage.js`)

| Ключ | Границы | Что | Кому |
|---|---|---|---|
| `icon_step_frames` | 1–4, обязателен | форма иконки «на N» кадров | иконка (svg без текста, не спутник) |
| `icon_overshoot` | 0–3, обязателен | перелёт входа иконки (`rise`, `pop`, `lift`) — коэффициент back-кривой | иконка |
| `step_frames` | 1–4 | форма любого узла «на N»: пиксель — на двойках/тройках, глина — покадрово, бойл | плашка, надпись целиком, часть, move |
| `grid_px` | 0–32 | позиция узла (левый верхний угол) — по сетке N px | пиксель |
| `overshoot` | 0–3 | перелёт входа любого узла: отскок плашки | комикс, глина |
| `move_overshoot` | 0–3 | перелёт в конце `move` | комикс |
| `jitter_px` | 0–6 | дрожь: сдвиг ±N px, новый на каждый рисунок (сид — узел и номер рисунка) | глина, лайн-бойл |

Необязательные выключены (1 / 0). **Посадка `move` и подъём `lift` содержания проверяются V6 с допуском
1,5 px**: сетка `grid_px` > 3 сдвигает посадку мимо цели и съедает подъём, дрожь `jitter_px` вместе со
ступенями «на тройках» — тоже (замер демо-фильма: пиксель с сеткой 8 — 5 провалов V6 и двойник на шве V10,
зин с дрожью 1 — 2 провала). Поэтому у содержания пикселя и зина — только ступени; сетку мира пиксель держит
в своём плагине. Непрозрачность всегда плавная — ступени и дрожь только у формы (V14 не
краснеет). Текст двигается только целиком, буквы не рвутся. Спутник берёт движение хозяина, сетка и дрожь у
него не свои (V13). Числа берутся из `style.json`, а не из `tokens.json`: это характер мира, не бренд.

## Звук (`style.json sfx.clips.<вид>`, исполняет `engine/audio/synth.py material`)

| Ключ | Границы | Что | Для чего |
|---|---|---|---|
| `wave` | `square` \| `soft` | меандр (жёсткое ограничение) / мягкое насыщение | 8 бит / глина, ткань |
| `bits` | 2–16 | разрядность (квантование амплитуды) | 8 бит |
| `hold` | 1–32 | битрейт: отсчёт держится N отсчётов | 8 бит |
| `noise_burst` | 0–1 | шумовой удар 30 мс от момента удара | хлопок, комикс, печать |
| `partials` | 0–1 | высокие парциалы (2,6–4,2 кГц) по огибающей | стеклянный звон |
| `grit` | 0–1 | шорох по огибающей | бумага, ткань, глина |
| `crackle` | 0–200 | щелчков треска в секунду | плёнка, винил |
| `lp_hz` | 500–12000 | срез верха (последним) | глухость: бумага, ткань, глина |

Время удара и длина клипа не меняются (материал — тембр). Новый ключ материала — правка общего кода
(`synth.py` + `registry.py SFX_CLIP_KEYS`), а не стиля: новый стиль берёт только сочетания этих ключей.

**Звук.** `build.py` пишет в `film.json` `scenes[].style` и `styles{<имя>: {label, sfx, world, fonts}}`;
`engine/audio/sfx.py plan()` берёт стиль сцены события и материал своего вида клипа, `synth.synth(..., mat)`
накладывает его на синтез. Время удара то же. Проходы: `sfx.py styles/<стиль>`, `music.py styles/<стиль> --mux`.

## style.css и world.css

Каждый селектор обязан содержать `[data-style="<name>"]` — иначе отказ сборки:

```css
.scene[data-style="<name>"] .k-icon svg { filter: url(#<name>-boil); }        /* содержание сцены */
#root[data-style="<name>"] .fr-title { font-family: var(--sty-<name>-title); } /* каркас — world.css */
```

Нельзя: `@import`, `@font-face` (шрифты объявляет сборка), `@media` и прочие @-правила, кроме
`@keyframes <name>-…`; цвет текста не ролью бренда; цвета узлов вне бренд ∪ decor; шрифт основного
текста; фильтры `sepia hue-rotate saturate grayscale invert contrast brightness` и `mix-blend-mode`
на содержании. Можно: заливка плашки цветом decor или другой ролью бренда (мир), `box-shadow`,
`filter: url(#…)` со смещением/шумом/размытием, кегль заголовка в пределах рамки.

## Заголовок кодом (`fonts.title.kind: "code"`)

Когда заголовок — не строка одним шрифтом (пиксели, пластилиновые буквы, вырезки зина), его рисует плагин:

```js
var r = StyleCore.codeTitle(api, api.styleScenes('<name>'), svgВСлоеBack, function (g, text, box) {
  StyleCore.pixelText(g, text, box.x, box.y + 2, { rows: 12, cell: 4, color: cfg.decor.ink });  // или свои буквы
});
// в render(t): r(t) — непрозрачность надписи = непрозрачность заголовка каркаса
```

`world.css`: `#root[data-style="<name>"] .fr-title .t { color: transparent; }` — текст каркаса остаётся
(раскладка, V10 по нему), но не виден. Проверки: V22 — у каждого видимого заголовка есть группа
`[data-style-title="<сцена>"]`, её `data-text` = тексту заголовка сцены, рамка группы — внутри рамки
заголовка каркаса (±2 px); V21 — контраст по пикселям в рамке строки заголовка, то есть по нарисованной
надписи. Что нарисовано буквами на самом деле, проверка не читает: это видно на листе кадров.
`pixelText` рисует шрифтом `o.font` — файлом стиля: у пикселя это Press Start 2P в своём размере,
`font: '8px ' + StyleCore.fontOf('pixel', 'decor')`, буква ложится в сетку 8×8 точно; без `o.font` — жирный
рубленый шрифт браузера (`sans-serif`, без имени). Шрифт-файл приходит на страницу не сразу: `codeTitle` рисует
надпись заново, пока `StyleCore.fontsReady()` не ответит «да»; своя надпись плагина, которая меряет буквы
шрифтом-файлом (ширина на холсте, растр), делает то же в `render` — образец: табло пикселя. Промеры и рендер ждут
загрузки шрифтов, поэтому кадр фильма всегда нарисован своим шрифтом.

## plugin.js — хуки

```js
(window.StagePlugins = window.StagePlugins || []).push(function (FILM, api) {
  var cfg = api.styleConfig('<name>');          // {params, motion, decor, world, objects, fonts} или null
  if (!cfg) return null;
  var layer = api.addLayer('<name>-back', 'back');
  if (cfg.world) { /* фон мира, предметы в зонах сцен: FILM.scenes[i].decor_zones (px) */ }
  else { /* замок: только фактура поверх фирменного фона */ }
  return {
    render: function (t) { /* кадр t — чистая функция времени */ },
    probe: function (t) { return { style: '<name>', weight: api.styleWeight('<name>', t), world: cfg.world }; }
  };
});
```

| Хук `api` | Что |
|---|---|
| `styleConfig(name)` | `{params, motion, decor, world, objects, fonts{title, decor}}` или `null` |
| `styleScenes(name)` | id сцен в этом стиле; `FILM.scenes[i].style`, `.decor_zones`, `.start`, `.end` |
| `styleAt(t)`, `styleWeight(name, t)` | стиль сцены в момент t; вес 0…1 (наплыв на стыке) |
| `sceneWeight(i, t)` | вес сцены i (предметы мира уходят и входят со своей сценой) |
| `frameOf(t)`, `stepTime(t, n)` | номер кадра (одно правило округления); время «на n» кадров |
| `addLayer(id, 'back' \| 'over')` | слой во весь кадр: `back` — под каркасом и содержанием (мир живёт тут), `over` — над содержанием (z 10). Класс `.style-layer` — их прячет кадр «без стиля» |
| `setStyle`, `setAttr`, `prog`, `lerp`, `clamp01`, `powerEase`, `mulberry32` | как у любого плагина ядра |

`window.StyleCore`: `rng`, `hash`, `grainTiles`, `paperTile`, `gridPaper`, `svg`, `defs`, `text`,
`boil` (кипение: feTurbulence → feDisplacementMap, `.set(seed)`), `hatch`, `halftone`, `vignette`,
`roughRect`, `roughEllipse`, `slots` (квадраты под предметы в зонах), `drawOn` (рисование линией; пунктир
— атрибут `data-dash`), `cssVar`, `rgbOf`, `layoutRect` (рамка узла по раскладке, без анимации), `textZones`
(зоны текста сцен стиля), `textWindows` (окна цветом `--c-paper` под ними — см. «Текст читается»). Общую фактуру или помощник, нужный двум стилям, кладут сюда;
предметы мира — в свой `plugin.js` (у каждого стиля свои).

**Правила плагина** (их ловят проверки):

- **Детерминизм (V24).** Случайность — только `StyleCore.rng(сид)`, сид — из `hash(id)` и номера кадра
  или рисунка. Не `Math.random`, не `Date`, не состояние «с прошлого кадра»: HyperFrames рендерит кусками
  в несколько потоков, кадры — в любом порядке. Зерно — сид от номера кадра без модуля.
- **Текст читается на ЛЮБОМ фильме (V21, жёстко).** Мир — в слое `back`. Стиль не знает, где на чужой
  сцене стоит текст, поэтому окна под ним не рисуются по дюймам стиля: в режиме мира плагин зовёт
  `StyleCore.textWindows(api, FILM, NAME, {parent: layer, pad: P.win_pad_px, css, feather, frame})` — под каждой
  зоной текста содержания (узел `.el` с непустым `.t`, и карточка тоже — на приглушённом уровне сквозь неё виден мир, + цели
  `move` текстовых узлов) встаёт окно цветом `--c-paper`: буквы стоят на поле бренда, контраст строки = контраст бренда при
  любой раскладке, даже у бледной роли (`accent` на светлом мире не дотягивает до 95 % — замер демо-фильма:
  2,2–2,6 против 2,93). Оформление окна — языком мира (`css`: ободок, тень, скругление, строчка; `feather` —
  мягкий край), середину не красить. `frame: true` — окна и под надписями каркаса (тёмный мир: стекло).
  Окна кладутся поверх фона и предметов мира (`parent: layer` после `svg`); обводки содержания, которые
  должны лежать на окне (кружки маркеров скетчбука), — `before: svg`. В `render(t)`: `wins.render(t)`.
  Контраст строки ≥ `tokens.json legibility.contrast_min` или ≥ 95 % того же текста без стиля. Кипение,
  ступени и перелёт — не на тексте. Проверка — на демо-фильме, а не только на пробе:
  `build.py demo --page --style <имя>` → `check.py demo --page --style <имя>`.
- **Палитра (V22).** Свои цвета — `cfg.decor`; бренд — `StyleCore.cssVar('--c-<роль>')`. Цвета узлов
  содержания и каркаса — бренд ∪ decor, текст — только бренд. Предметы мира в своих слоях — любые цвета
  `decor`. Слой `over` (над содержанием) — без `mix-blend-mode`, `backdrop-filter` и перекрашивающих
  `filter` (sepia, hue-rotate…): перекраска мира (сепия плёнки, тон бумаги) — только в слое `back`.
- **Приглушать текст нельзя (V21).** Строка, видимая без стиля на 1,0, мерится в кадре со стилем при любой
  непрозрачности, которую стиль ей дал; спрятанная строка (`display: none`) — провал.
- **Вспышки (V23).** Отсчёт, мерцание, мигание — не больше `legibility.flash_max_per_sec` пар перепадов
  ≥ `flash_delta` в секунду в любой клетке сетки `flash_grid`.
- **Замок.** При `cfg.world === false` — ни фона мира, ни предметов, ни decor на узлах: только фактура.

## Как сделать новый стиль — по шагам

1. Скопировать ближайший образец: `film/` (мир-слой: зал, окно, предметы-реквизит) или `sketchbook/`
   (мир-рисунок: лист, рисунки линией, обводка содержания) в `styles/<name>/`; поправить `name`, `label`.
2. Посмотреть референс стиля (эталон пользователя из `links.md`, спрашивается на интервью), выписать: фон, 4–6 цветов мира (`decor`),
   шрифт заголовка (файл с кириллицей и лицензией на распространение — OFL; сборка откажет без кириллицы), ≥ 5 предметов
   (`objects`), движение (`motion`, свои анимации предметов), звук (`sfx`).
3. Нарисовать мир в `plugin.js` (оба режима: `cfg.world`), CSS — только `[data-style="<name>"]`,
   шрифт заголовка — в `world.css`.
4. Дописать `"<name>"` в `project/films/styles.json → styles` (список проходов демо — не регистрация).
5. `build.py styles --page --style <name>` → `check.py styles/<name> --page` зелёный (V1–V24).
6. `build.py styles` → `<out>/styles/styles-sheet.png`: положить рядом с референсом стиля
   и ответить, узнаётся ли стиль с одного кадра; что совпало и чего нет — в отчёт.
7. Замок: копия проекта с `style_brand_lock: true`, `check.py styles/<name> --page` зелёный.

```
                                                            со всем движением и звуком: сборка и check.py целиком)

                                                            роняет контраст подписи», с --samples — 2 образца
```

Сцена-проба `style-probe` — калибровка механизма, а не приёмка: стиль сдаётся, когда зелёный и проход
демо-фильма (на пробе текст стоит там, где стиль его ждёт; на фильме — где решил режиссёр).

Цена рендера 12 с ролика 1920×1080: без стиля ≈ 4 с на секунду ролика, скетчбук ≈ 7, плёнка ≈ 11 и пик
временных кадров ≈ 1,2 ГБ (зерно не сжимается в PNG) — длинный фильм в плёнке рендерить с `--chunk-sec 10`.
Промер стиля (`_core/probe_style.mjs`) снимает каждый кадр в 1/10 размера: ≈ 25–60 с на 12 с ролика.

## Миры с набором сцены

Шесть стилей сверх мира дают сцене **набор** — инструменты, которыми разметка сцены рисует свой мир сама:

| Стиль | Набор | Что в нём |
|---|---|---|
| `flat-edu` | `window.FlatEdu` | предметы студии по узлам `data-obj`, роли decor как `--d-<роль>`, марионетка `rig`, дорожки `track` / `steps`, рот `mouth`, моргание `blink`, двойник надписи за кадром `gate` |
| `pixel` | `window.PixelKit` | спрайты из клеток `px`, рисунки `art` (лошадь, заяц, снеговик, хвойное дерево, блок, монета, огонь), дом с вывеской `house`, гирлянда `garland`, такси `taxi`, надпись клетками `text` |
| `comic` | `window.ComicKit` | тушь `ink`, перо переменной толщины `taper`, полутон `dots`, звезда-взрыв `star`, такси `taxi`, вертолёт `heli`, проход лопастей `bladeWedge` (шов двух миров) |
| `paper-cut` | `window.PaperKit` | лист с тенью `sheet`, облака `cloud` / `bank`, вертолёт `heli` (с кабиной для героя), `bladeWedge`, вдавленные буквы `inset` |
| `neon-line` | `window.NeonKit` | трубка `neon`, волна рисования `drawIn`, разгорание `strike`, дыхание `breath`, бегущий свет `flow`, пятно `pool` и луч `beam`, звенья `ik` и контур конечности `limbPath` |
| `tv-splash` | `window.TvSplash` | свет мира от сцены (`light`, `rings`, `hits`, `jolt`), разгорание `strike`, дыхание `breath` |

**Подключение.** Сцена регистрируется из своей разметки (`<script>` в конце `markup.html`):

```js
(window.ComicScenes = window.ComicScenes || []).push({ scene: '<id сцены>', setup: function (kit, FILM, api) {
  var t0 = kit.at({ reply: 3, at: 0.4, offset: -0.1 });      // якорь → секунды: секунд в сцене нет
  /* рисуем мир в свои элементы (.el) инструментами kit, цвета мира — kit.decor */
  return { frame: function (t) { /* кадр — чистая функция t */ } };
} });
```

Имена списков: `FlatEduScenes`, `PixelScenes`, `ComicScenes`, `PaperScenes`, `NeonScenes`, `TvSplashScenes`. Сцена,
подключённая к нескольким наборам, идёт в любом из этих стилей. Образец — `project/scenes/kit-probe/` и фильм
`films/kits.json` (сцена-проба во всех шести мирах: `build.py kits`, `check.py kits --page`).

**Время — якорями.** `kit.at({reply, at, offset})` (он же `StyleCore.when(FILM, якорь)`) считает секунды по тому же
правилу, что биты раскадровки: начало реплики + доля её длины + сдвиг. Переозвучка сдвигает действие вместе с речью.
Действие, которое должно попасть в промер (жест, появление), ставится на якорь бита раскадровки: промер снимает
кадры вокруг битов.

**Действия — метками.** `kit.cues(сцена)` (он же `StyleCore.cues(FILM, сцена)`) отдаёт метки действий мира сцены
(раскадровка `plugins.act.cues`, плагин `act` — `engine/video/plugins/README.md`) так, как их собрала сборка:
`{id, t — секунды фильма, who, do, motion, m — числа tokens.json motion.act.<motion>, span — длина}`. Мир стиля
ставит своё движение на ту же метку, что исполняет разметка сцены (`window.ActExec`), — время одно на всех, а
промер снимает кадры вокруг каждой метки сам (V31 — метка исполнена). Сцена без меток — пустой список. Камера сцены
(метки `who: "cam"`) — движка: мир, который набор рисует в элемент сцены, едет с камерой вместе с содержанием; фон
слоя стиля (под сценой) стоит. Своей «камеры набора» (рамки мира в момент t для фона) в шаблоне нет: фону, которому
нужно ехать, хватает тех же меток `kit.cues` с `who: "cam"`. Образец — `kit-probe`: голова и рука манекена — метки «go» и «wave», мир каждого набора трогается с места на «go».

**Герой и надписи — данные проекта.** В коде стилей нет ни героев, ни слов: героя рисует разметка сцены (SVG в
`markup.html` или инструментами набора), его цвета — роли палитры проекта `tokens.json palette` (`var(--c-<роль>)`:
hex в разметке запрещён, V12); свой вариант мира с дополнительными ролями decor — папкой `<проект>/styles/<имя>/`.
Облик героя согласуется листом рядом с эталоном до первой сцены (`process/02-design.md` скила, «Лист облика героя»).

**Контракт рига (`FlatEdu.rig`).** Герой — SVG с частями по id `<сцена>--<кто>-<часть>`: `figure`, `head`,
`hair-back`, `pupils`, `brows`, наборы «один из» `eyes-<open|closed|happy>`, `brows-<neutral|raised|frown>`,
`mouth-<closed|ajar|a|o|smile|grin>`, `pose-<free|crossed|hold>`, `hand-<left|right>-<relaxed|open|point>`; шарниры
`arm-<left|right>-upper`, `arm-<left|right>-fore`, `leg-<left|right>` вращаются вокруг `data-pivot="x y"`; полотно
фигуры — ось x = 400, пояс y = 1000. `rig(prefix).apply(state)` ставит позу целиком одним объектом состояния.
Мимику не вести уровнем звука покадрово: один мягкий акцент на реплику (класс дефектов 34).

**Поза: рук две (V25).** Конечность героя, у которой есть поднятый и опущенный вариант, размечается
`StyleCore.limb(узел, '<герой>', '<сторона>', 'up' | 'down')` (или атрибутом `data-limb="<герой>:<сторона>:<up|down>"`
в разметке). Промер DOM отдаёт, какие конечности видны в кадре; при видимой поднятой видимая опущенная той же
стороны — третья рука, условие красное. Скрывать — `visibility: hidden` или `display: none` на узле.

**Шов двух стилей.** Непрозрачность слоя мира — `api.styleOpacity(NAME, t, layer)` (а не `styleWeight`): на шве
нижний слой стоит на 1, верхний наплывает своим весом — кадр = смесь двух миров. Если оба слоя гасить весами, на
середине шва сквозь них светит фон страницы. Все стили движка сделаны так; новый стиль делает так же.

**Сцена с каркасом и без.** В сцене с каркасом учебного жанра новые миры (`flat-edu`, `neon-line`, `tv-splash`)
кладут светлые окна под текст (`StyleCore.textWindows`) и предметы в `decor_zones`. Наборы `pixel`, `comic` и
`paper-cut` различают сцену, объявившую себя без каркаса (`FILM.scenes[i].frame === false`): пейзаж каркаса для
неё не рисуется. Самого переключателя каркаса по сцене в шаблоне нет — каркас задаёт `project.json frame`.
