# Словарь опасных слов для синтеза: омографы и подвижное ударение.
# Строка: слово  # основание. Совпадение — по целому слову, без учёта регистра, ё = е.
# Знака ударения у MiniMax нет: находку лечат перестройкой фразы в speech_edits.json
# («беды ещё нет» → «беда ещё не случилась») или принимают на слух (allow + why).
# После первой находки класса — прогон всей нарезки, а не точечная правка (урок прошлого ролика).
#
# --- услышано на прошлом ролике -----------------------------------------------
беды      # «БЕды» вместо «бедЫ» (род. ед. ↔ им. мн.)
головы    # «гОловы» вместо «головЫ» в «раньше головы»
#
# --- тот же класс: род. ед. на -ы/-и с ударением на окончании ↔ им. мн. на основе
руки      # рукИ (род. ед.) / рУки (им. мн.) — соседка «головы» в той же реплике
ноги      # ногИ / нОги
воды      # водЫ / вОды
горы      # горЫ / гОры
стены     # стенЫ / стЕны
доски     # доскИ / дОски
среды     # срЕды (им. мн.) / средЫ (род. ед.)
сети      # сЕти / сетИ («в сети»): частое слово учебных текстов по ИБ
души      # душИ / дУши
#
# --- классические омографы --------------------------------------------------
замок     # зАмок / замОк
замки     # зАмки / замкИ
мука      # мУка / мукА
атлас     # Атлас / атлАс
орган     # Орган / оргАн
хлопок    # хлОпок / хлопОк
плачу     # плАчу / плачУ
дорогой   # дорогОй / дОрогой
#
# Не включены намеренно: «уже», «все», «стоит» — омографы, но в учебной речи
# встречаются в каждой второй реплике и синтез читает их по контексту верно;
# запрет, краснеющий на каждой строке, превращает белый список в свалку.
