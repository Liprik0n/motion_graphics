# Подключения: что подключать к скилу и что нет

Читать, когда спрашивают, нужно ли подключать программы через MCP, или когда этапу 2 нужна готовая анимация. Скил работает и
без подключений: отсутствие сервера не останавливает этап, готовое ищется в каталоге `../catalog/sources.md` руками.

## Правило входа

**Вход делает пользователь, в браузере.** Логин, пароль, ключ и токен агенту не передаются и в чат не пишутся: на вопрос,
как передать агенту доступ, ответ один — войди сам. Подключение к Claude Code идёт командой `claude mcp add`, затем в сессии `/mcp`:
открывается окно входа в браузере, пользователь входит и разрешает доступ. Агент это окно не заполняет и значения не видит.

## Что подключать: LottieFiles

Два сервера одной компании, по желанию. Оба на момент записи **не подключены**: подключает и входит заказчик, проба Creator
не проводилась.

| Сервер | Что даёт | Как подключить | Что неизвестно |
|---|---|---|---|
| LottieFiles MCP | поиск готовых анимаций в рабочем пространстве заказчика, скачивание файла Lottie | `claude mcp add --transport http <имя> <адрес сервера>`, затем `/mcp` и вход в браузере | адрес берётся со страницы `https://lottiefiles.com/mcp`, в этот файл не вписан: не проверен; лимиты и состав рабочего пространства не измерены |
| Creator MCP | сборка анимации Lottie по описанию словами | та же форма команды со своим адресом, затем `/mcp` | качество, лимиты, время и стоимость не измерены; проба — на одном элементе пробной сцены, не на материалах заказчика |

Скачанный файл Lottie — материал: строка в `project/materials.json` с источником и лицензией (Lottie Simple License разрешает
коммерческое использование без подписи; «не собирать конкурирующий сервис»). Плагин Lottie шаблона проверен на
настоящем проигрывателе (пакет `lottie-web` 5.12.2) на файле из фигур; скачанная с LottieFiles анимация не проигрывалась.

## Что отложено

**Blender.** Отложен по слову заказчика. Причины: нужна видеокарта (EEVEE работает только на ней), на
этой машине её нет, а открытке и учебным роликам 3D не нужен. Вернуться, когда нужен 3D-ролик и есть машина с видеокартой 12+ ГБ
(`hardware.md`).

## Что не подключать, и почему

| Сервер | Почему не сейчас |
|---|---|
| Comfy Cloud MCP | генерация картинок на облачных видеокартах за платные кредиты; заказчик генерирует сам, скил пишет список и промты |
| ElevenLabs MCP | голос и кредиты; озвучка идёт через свой адаптер провайдера с лимитом знаков и согласием в точке расхода; звуковые эффекты сервера не подтверждены |
| Figma, Canva | коннекторы настроены, не авторизованы; польза для раскадровок и плашек не доказана, у Canva прозрачный PNG только в платном тарифе |
| Blender MCP | без видеокарты бесполезен |
| After Effects | официального MCP нет: закрытая бета в 2027 |
| Freesound, Pixabay, ffmpeg (сторонние MCP) | чужой код и чужие ключи; прямая ссылка на страницу с лицензией и оболочка вокруг `ffmpeg` проще |

## Навыки HyperFrames

Навыки движка ставятся командой `npx skills add heygen-com/hyperframes`. Сборка сейчас отключает их установку
(`HYPERFRAMES_SKIP_SKILLS=1`): ставить без слова пользователя нельзя; польза для скила не измерена.

## Если сервер подключён

Агент вызывает его инструменты в обычном порядке; файл кладёт в `project/assets/`, строка в `materials.json` с лицензией обязательна,
`check_materials.py` краснеет без неё. Материалы заказчика на чужой сервер не отправляются без его слова по каждому проекту.
