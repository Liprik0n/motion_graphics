# Стиль — целый мир, подключаемый папкой, с замком бренда

## Контекст

Первая версия 11 стилей была ограничена: стиль менял фактуру, обводку, движение и звук, но не палитру и не шрифт. На листе кадров стили слились: узнаваемый стиль — целый мир. Пользователь выбрал «Стиль — целый мир».

## Решение

Стиль задаёт фон, палитру декора, шрифт заголовков с кириллицей (системный или нарисованный кодом, без скачивания), набор нарисованных кодом предметов (не меньше пяти), характер движения и звуковой материал. Основной текст остаётся фирменным шрифтом с контрастом не ниже порога токенов. Бренд — логотип и акцентный цвет. `project.json style_brand_lock: true` возвращает прежнее поведение «только фактура».

Стиль — папка `engine/video/styles/<name>/` (`style.json`, `style.css`, `world.css`, `plugin.js`). Регистрации нет: стиль ищется по папке, сначала в `<проект>/styles`, затем в engine. Кадр стиля — чистая функция времени. Проверки V21–V24: читаемость, бренд и decor, вспышки ≤ 3 в секунду, детерминизм (два рендера бит в бит).

## Почему

Стиль не узнаётся с одного кадра, если фон, предметы и заголовки остаются теми же. Замок бренда сохраняет прежний вариант там, где фирменный вид важнее: учебные ролики компании.

Отвергнуто:
- **Стиль только как фактура (первая версия).** На листе кадров стили сливаются.
- **Скачиваемые шрифты и растровые предметы.** Нужна независимость от сети и установки; всё рисуется кодом и берёт системные шрифты.
- **Подмена основного текста шрифтом стиля.** Страдает читаемость; основной текст остаётся фирменным.

## Последствия

- Шрифты стилей — системные Windows: на другой машине заголовок падает на фирменный (записано в журнале сборки).
- Не меньше пяти нарисованных предметов на каждый из 11 стилей — заметный объём кода, который приходится поддерживать.
- Для учебного жанра ткань и глина — «редко, обоснуй» (`catalog/styles.md`).
- Мир стиля меняет вид всего кадра, поэтому каждый новый стиль обязан пройти V21–V24, включая порчи.
- Это решение заменило прежнее ограничение «только фактура»; следы старой формулировки в других документах — ошибка, а не допуск.

## Поправка 2026-11-22: шрифты стилей — файлы под OFL

**Отменено:** пункт «Скачиваемые шрифты» из отвергнутого и последствие «шрифты стилей — системные Windows». Слова решения «шрифт заголовков — системный или нарисованный кодом, без скачивания» больше не действуют.

**Теперь:** шрифт заголовка и надписей каждого стиля движка — файл в `template/engine/video/assets/fonts/` под лицензией SIL OFL 1.1 (Google Fonts, с кириллицей); семейство, источник, размер и файл лицензии записаны в `README.md` той же папки. Стили движка системных шрифтов по имени не называют — ни в `style.json`, ни в `plugin.js`. Заголовки, которые рисует код (пиксель, глина, зин), берут буквы из тех же файлов: у пикселя — пиксельный шрифт в своём размере, у зина — свои роли шрифтов для вырезок. Поиск файла шрифта: папка стиля → шрифты проекта → шрифты движка → системная папка (последнее — только для своего стиля проекта).

**Почему:** системный шрифт нельзя ни перенести на другую машину, ни опубликовать вместе со скилом: на машине без него заголовок молча падал на фирменный, и мир стиля терял лицо. Довод прежнего решения — независимость от сети — сохранён иначе: файлы лежат в скиле, при сборке и рендере сеть не нужна. Заказчик согласился на шрифты файлами.

**Последствия:**
- Вид заголовков стилей изменился; лист «было / стало» — `catalog/img/style-titles-before-after.png`.
- Скил вырос примерно на 3,3 МБ (тринадцать файлов шрифтов и одиннадцать текстов лицензии).
- Новый шрифт стиля — это файл с правом распространения, строка в `assets/fonts/README.md` и файл лицензии рядом.
- Шрифт-файл приходит на страницу не сразу: надпись, которую код рисует по его метрикам, перерисовывается, пока шрифты не загрузятся (`StyleCore.fontsReady`, `styles/README.md`).

Пункт о растровых предметах («всё рисуется кодом») эта поправка не трогает: его пересматривает отдельное решение.
