# Задание фактчекеру — <документ / строки>

Агент `motion-factcheck` (opus / medium), свежий контекст, **только находки — текст не правит**.
Читает `process/01-script.md` («Фактчек по классам»).

```
ПРОВЕРЬ: <сценарий | rows.json | текст на экране сцен> строки <a–b>.
ПЕРВОИСТОЧНИК: <пути к документам> (+ конспект с номерами пунктов, если есть).
КЛАССЫ:
  квантор — «все», «первыми», «единственный», «всегда», «никогда» без опоры в источнике;
  порядок — «строго по порядку», «сначала… потом», порядок на экране ≠ порядку речи;
  открытость перечня — открытый перечень подан закрытым, пропало «например», «и другие».
ЕЩЁ: сроки и запреты — дословно, без округления; число, которого нет в источнике, —
  находка («в источнике числа нет»).
НЕ ДЕЛАЙ: не правь текст; ссылки на пункты — только в отчёте, в речь их не предлагать.
```

## Отчёт

```
ИТОГ: строк проверено N; находок M (квантор a · порядок b · перечень c · срок/запрет d)
ТАБЛИЦА: строка → класс → было → источник (пункт, цитата ≤ 15 слов) → как исправить
СОМНЕНИЯ: где источник сам противоречив — привести оба места, не решать за пользователя
```
