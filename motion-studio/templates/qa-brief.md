# Задание визуальному QA — <версия / швы>

Агент `motion-qa` (opus / medium), свежий контекст, **без права правки**. Читает `SKILL.md`,
`process/03-motion.md` (законы и их проверки), `checklists/defect-classes.md`.

```
СМОТРИ: out/<film>/sheet/*.png (листы кадров) и полосы кадров ±0,5 с вокруг каждого шва
  и перехода: швы <список>. Видео: out/<film>/video.mp4 — если открыть нечем, так и написать.
  Сцены с героем и швы между мирами — по видео или по полосе через всё действие, не по листу.
СЛОВА ПОЛЬЗОВАТЕЛЯ: <дословно — что он просил в этой версии>.
ЗАКРЫТЫЙ СПИСОК: телепорт · дёрганье · резкое появление · повтор приёма · обрезка краем ·
  мелкий текст · пустой кадр · текст на тексте · двойник · элемент без опоры ·
  спутник отстаёт · порядок экрана ≠ порядку речи · вспышки · расхождение с раскадровкой ·
  движение задом наперёд · жест или взгляд мимо цели · действие без следа ·
  лишняя часть тела · дребезг на речи.
ГЛАВНЫЙ ВОПРОС: понятен ли каждый элемент зрителю без голоса?
НЕ ДЕЛАЙ: не правь файлы, не предлагай передизайн; утверждённое пользователем — сохранить.
```

## Отчёт

```
ТРИ ХУДШИХ МЕСТА: момент {reply, at} или таймкод → класс → что видно → что должно быть
ОСТАЛЬНОЕ: по классам закрытого списка, с моментом
СМОТРЕЛ: какие листы и полосы; В ДВИЖЕНИИ: да / нет; НЕ СМОТРЕЛ: что и почему
ВЕРДИКТ: можно показывать / нельзя (и что блокирует)
```
