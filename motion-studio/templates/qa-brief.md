# Задание визуальному QA — <версия / швы>

Агент `motion-qa` (opus / medium), свежий контекст, **без права правки**. Что читает до работы — в его карточке
`agents/motion-qa.md`. Закрытый список дефектов — `checklists/closed-list.md`, здесь он не повторяется.

```
СМОТРИ: полосы кадров project/out/<film>/strips/ — каждой сцены и каждого шва: сцены <список>, швы <список>.
  Их положил исполнитель, режиссёр их уже принял; бери готовые. Нет полосы — сними. Сцена и момент — с --no-build
  (страницу фильма собрал оркестратор; нет страницы — не собирай, напиши); шов — без --no-build (у шва своя
  страница пары project/out/<film>--<a>,<b>/, её собирает сама полоса; сборка упала — напиши):
    "$PY" engine/tools/strip.py <film> --scene <id> --video --no-build
    "$PY" engine/tools/strip.py <film> --at <реплика>:<доля> --height <высота полотна> --no-build   # мелкое — крупно
    "$PY" engine/tools/strip.py <film> --seam <a>:<b> --video
  Листы project/out/<film>/sheet/*.png — для вопросов про вид. Видео: strips/<имя>/clip.mp4 или video.mp4.
  ВИДЕО ОТКРЫТЬ НЕЧЕМ — замена, и она считается просмотром в движении:
    "$PY" engine/tools/strip.py <film> --scene <id> --fps <fps фильма> --no-build --name scene-<id>-move
    "$PY" engine/tools/strip.py <film> --seam <a>:<b> --fps <fps фильма> --name seam-<a>-<b>-move      # шов — без --no-build
    "<ffmpeg>" -i project/out/<film>/strips/scene-<id>-move/frames/%04d.png -vf "tblend=all_mode=difference,tile=6x10" -frames:v 1 <scratchpad>/diff-<id>.png
  (<ffmpeg> — "$PY" -c "import imageio_ffmpeg; print(imageio_ffmpeg.get_ffmpeg_exe())"; чёрное — стоит, светлое —
  сдвинулось). В отчёте: «в движении — по кадрам и разнице кадров, видео не открывал».
  Сцена и шов без полосы в отчёте — не смотрено, а не «чисто».
СЛОВА ПОЛЬЗОВАТЕЛЯ: <дословно — что он просил в этой версии>.
СПИСОК: checklists/closed-list.md — целиком, включая «предмет неправдоподобен или неуместен», «сцена статична»,
  «край вырезки виден» и «вне списка».
ГЛАВНЫЙ ВОПРОС: понятен ли каждый элемент зрителю без голоса?
НЕ ДЕЛАЙ: не правь файлы, не предлагай передизайн; утверждённое пользователем — сохранить.
```

## Отчёт

```
ТРИ ХУДШИХ МЕСТА: момент {reply, at} или таймкод, имя полосы → дефект → что видно → что должно быть
ОСТАЛЬНОЕ: по строкам закрытого списка, с моментом
ВНЕ СПИСКА: что видно и в списке не названо: где, чем мешает зрителю (или «нет»)
СМОТРЕЛ: какие полосы; В ДВИЖЕНИИ: видео / по кадрам и разнице кадров / нет; НЕ СМОТРЕЛ: что и почему
ЗАМОК: сколько минут ждал замок Chrome (отдельно от работы)
ВЕРДИКТ: можно показывать / нельзя (и что блокирует)
```
