# Задание исполнителю сцены — <id>

Агент `motion-scene` (opus / medium). Читает `SKILL.md`, `process/03-motion.md`, замысел
`director/scene-NN.md` и раскадровку `scenes/<id>/storyboard.json`.

```
СЦЕНА <id>: выполни раскадровку scenes/<id>/storyboard.json по замыслу director/scene-NN.md.
МЕНЯТЬ: только scenes/<id>/ (данные и markup.html). Движок, каркас, звук, чужие сцены — не трогать.
ВЫХОД: только out/<таск>/ и свой scratchpad <путь>. Фильм не рендерить.
ПРАВИЛА (process/03-motion.md): кадр — функция времени; один твин на свойство в момент;
  set в начале, to дальше, видимое не set-ить; только transform и opacity;
  числа движения — из tokens.json, своих не вводить; новое появление — событием под голос.
ПРОВЕРКА:
  1) "$PY" engine/video/storyboard.py scenes/<id>/storyboard.json
  2) "$PY" engine/video/build.py <film> --only <id>,<сосед> --page
  3) "$PY" engine/video/check.py <film> --only <id>,<сосед> --page   → зелёный
  4) лист кадров — открыть Read'ом и пройти закрытый список: телепорт, дёрганье, повтор приёма,
     обрезка краем, мелкий текст, пустой кадр, наложение, элемент без опоры,
     расхождение с раскадровкой, каждый Must-check режиссёра.
  Минимум 2 круга «страница → лист → правка».
ПРАВКА ПО ЗАМЕЧАНИЮ: сначала опиши, что не так на кадре, потом правь только названное.
НЕХВАТКА ДВИЖКА: не обходить ручными сдвигами данных — записать в CONCERNS, уйдёт в needs.
```

## Отчёт

```
ГОТОВО: <id>
ФАЙЛЫ: пути
ПРОВЕРКА: команды → результат (условий N, красных 0); лист кадров просмотрен: да / нет
ПОСЛЕДНИЙ КАДР: id → x, y, scale, opacity, текст (по каждому видимому элементу)
ИСПОЛЬЗОВАННЫЕ ПРИЁМЫ: имя приёма → бит
КАК СОБРАНО: тайминги, компромиссы, самое слабое место (оставлено сознательно)
CONCERNS: нехватка движка → needs; отступления от раскадровки и почему
```
