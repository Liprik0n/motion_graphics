# Задание режиссёру — <сцены / волна>

Агент `motion-director` (opus / xhigh). Что читает до работы — в его карточке `agents/motion-director.md`.

```
РАМКА: сцены <sNN–sMM> «<заголовки>», реплики <a–b> из rows.json; длительности — из манифеста озвучки.
ЗАЧЕМ: что зритель должен понять и запомнить в каждой сцене (1–3 факта дословно из нарезки).
СЛОВА ПОЛЬЗОВАТЕЛЯ: <дословно, в кавычках, с датой>.
РЕФЕРЕНС: <refs/<имя>/analysis.md | нет>. Брать: <МЕХАНИКА | ПОДАЧА | ТОЧНО>. Не копировать: <…>.
СТИЛЬ: <фирменный | пресет из catalog/styles.md>. Never фильма: director/bible.md §«Запреты».
МАТЕРИАЛЫ: что рисуем кодом, что берём растром или готовой анимацией; у каждого предмета — источник (таблица
  «предмет → источник», project/materials.json).
СОСЕДИ: стык с <sNN-1> и <sMM+1> — их Start / End из чужих раскадровок не менять, только согласовать.
СДАТЬ:
  1) director/scene-<id>.md по dense-полям (Brief, Objects, Sequence, Start / End → next, Never,
     Must-check, Unknowns, Code map); у чисел метки [M] / [O] / [H];
  2) scenes/<id>/storyboard.json — время только {reply, at, offset}; проходит storyboard.py;
  3) director/transition-<a>-<b>.md для каждого стыка (<id>, <a>, <b> — id сцен из films/<film>.json);
  4) эскиз композиции КАЖДОЙ сцены ролика director/sketches/<id>-*.png в размер полотна (project.json canvas) —
     лист всех сцен идёт заказчику до сборки;
  5) проба ключевого приёма до пилота: задание исполнителю director/probe-<приём>.md (что решает проба, моменты
     «должно быть / не должно быть»), раскадровка приёма и фильм пробы project/films/probe.json из одной этой сцены;
     страницу собирает исполнитель сцены, лист и полосу принимаешь ты (второй вызов);
  6) needs: что нужно от движка + критерий для проверки;
  7) строки в director/priemy-used.md.
УСЛОВИЯ ИСПОЛНИТЕЛЮ: каждое сначала проверь на эскизе или пробе — чего на кадре не видно, того не требуют;
  «облик как на принятом кадре» — с путём к кадру; в командах съёмки — --height, на которой условие видно.
ЗАПРЕЩЕНО: секунды в раскадровке; ширины надписей числами (только «промер DOM»);
  приём, уже стоящий в соседней сцене; правка движка и чужих сцен.
ПИШИ АТОМАРНО: во временный файл и переименование.
```

## Приёмка кадров (второй вызов)

```
ПРИМИ: полосы исполнителя project/out/<film>/strips/ — сцену <id> и её швы — против своих эскизов и Must-check.
  ЭТАЛОН: <эскизы | при пересборке сданного ролика — кадры сданного ролика: путь>.
  Полосы уже сняты, открывай их; нет нужной — сцена и момент с --no-build (страница фильма собрана; без ключа —
  только после своей правки чисел: полоса пересоберёт страницу всего фильма); шов — всегда без --no-build
  (у шва своя страница пары, её собирает сама полоса):
    "$PY" engine/tools/strip.py <film> --scene <id> --no-build   |   --pair <папка прежней полосы>
    "$PY" engine/tools/strip.py <film> --at <реплика>:<доля> --height <высота полотна> --no-build   # момент крупно
    "$PY" engine/tools/strip.py <film> --seam <a>:<b>
  Проходи checklists/closed-list.md. QA получит полосы после твоего слова.
ОТВЕТ: «принято» или расхождения: кадр {reply, at} → эскиз → что не так → что поправить (≤ 14 пунктов).
  Дефекты вне списка — отдельной строкой «ВНЕ СПИСКА».
```

## Отчёт

```
ГОТОВО: сцены <id…> — раскадровка / стык / эскизы / проба приёма
ФАЙЛЫ: пути
ПРОВЕРКА: storyboard.py project/scenes/<id>/storyboard.json → OK; Must-check: N пунктов → M условий + K пунктов просмотра
NEEDS: что нужно от движка, с критерием (или «нет»)
ВОПРОСЫ: что не решил сам — для пользователя (или «нет»)
ОТСТУПЛЕНИЯ: от библии и почему
ЗАМОК: сколько минут ждал замок Chrome (отдельно от работы)
```
