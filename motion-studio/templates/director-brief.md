# Задание режиссёру — <сцены / волна>

Агент `motion-director` (opus / xhigh). Читает `SKILL.md`, `process/03-motion.md`,
`process/04-storyboard.md`; для стиля — `process/02-design.md`, `process/10-references.md`.

```
РАМКА: сцены <sNN–sMM> «<заголовки>», реплики <a–b> из rows.json; длительности — из манифеста озвучки.
ЗАЧЕМ: что зритель должен понять и запомнить в каждой сцене (1–3 факта дословно из нарезки).
СЛОВА ПОЛЬЗОВАТЕЛЯ: <дословно, в кавычках, с датой>.
РЕФЕРЕНС: <refs/<имя>/analysis.md | нет>. Брать: <МЕХАНИКА | ПОДАЧА | ТОЧНО>. Не копировать: <…>.
СТИЛЬ: <фирменный | пресет из catalog/styles.md>. Never фильма: director/bible.md §«Запреты».
СОСЕДИ: стык с <sNN-1> и <sMM+1> — их Start / End из чужих раскадровок не менять, только согласовать.
СДАТЬ:
  1) director/scene-NN.md по dense-полям (Brief, Objects, Sequence, Start / End → next, Never,
     Must-check, Unknowns, Code map); у чисел метки [M] / [O] / [H];
  2) scenes/<id>/storyboard.json — время только {reply, at, offset}; проходит storyboard.py;
  3) director/transition-NN-MM.md для каждого стыка;
  4) эскизы ключевых кадров director/sketches/<id>-*.png;
  5) needs: что нужно от движка + критерий для проверки;
  6) строки в director/priemy-used.md.
ЗАПРЕЩЕНО: секунды в раскадровке; ширины надписей числами (только «промер DOM»);
  приём, уже стоящий в соседней сцене; правка движка и чужих сцен.
ПИШИ АТОМАРНО: во временный файл и переименование.
```

## Приёмка кадров (второй вызов)

```
ПРИМИ: лист кадров out/<таск>/sheet/*.png сцены <id> против своих эскизов и Must-check.
ОТВЕТ: «принято» или расхождения: кадр {reply, at} → эскиз → что не так → что поправить (≤ 14 пунктов).
```

## Отчёт

```
ГОТОВО: сцены <id…> — раскадровка / стык / эскизы
ФАЙЛЫ: пути
ПРОВЕРКА: storyboard.py scenes/<id>/storyboard.json → OK; Must-check: N пунктов → M условий + K пунктов просмотра
NEEDS: что нужно от движка, с критерием (или «нет»)
ВОПРОСЫ: что не решил сам — для пользователя (или «нет»)
ОТСТУПЛЕНИЯ: от библии и почему
```
