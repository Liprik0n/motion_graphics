# Задание звукорежиссёру — <этап: текст в синтез | промер голоса | музыка | эффекты>

Агент `motion-sound` (opus / medium). Что читает до работы — в его карточке `agents/motion-sound.md`.

```
ВХОД: rows.json, voices.json, speech_edits.json, music.json, sfx.json проекта; film.json — для эффектов.
ДО СИНТЕЗА:
  speech_lint.py → каждая находка закрыта записью в speech_edits.json («строка → speech → why»)
  или белым списком; после первой находки класса — вся нарезка по homographs.txt.
  tts.py --estimate → смета: знаков, минут.
СИНТЕЗ: только после слова пользователя, с лимитом <N> знаков: tts.py --rows <a-b> --yes-i-pay --max-chars N.
  Значения .env не печатать нигде; ошибка доступа к голосу — сначала tts.py --voices (бесплатно).
ПОСЛЕ СИНТЕЗА: check_audio.py — reply = cache байт в байт; внутренние паузы ≥ 0,35 с не на знаке;
  факт/расчёт > 1,6; медианы громкости голосов ≤ 0,5 дБ после gain_db; пик.
  Каждый новый дубль — тем же промером до отдачи пользователю.
МУЗЫКА: 3–5 треков из библиотеки с лицензией на прослушку; ducking ≥ 20 дБ; −16 LUFS; −1 dBTP.
ЭФФЕКТЫ: из событий film.json; ≥ 1,5 с между звуками; под речью ≤ −18 дБ; в паузе ≤ −10 дБ;
  sfx-proba.mp3 до рендера.
СКАЧИВАНИЕ: любой файл — только по явному «да» пользователя, строка в манифесте ассетов с лицензией.
ЗАПРЕЩЕНО: править смысл сценария (документ остаётся дословным); платный вызов без слова.
```

## Отчёт

```
ГОТОВО: этап
ФАЙЛЫ: пути
СМЕТА: знаков запрошено / израсходовано / лимит
НАХОДКИ: строка → класс → число (пауза 0,52 с, факт/расчёт 1,8, разница 0,7 дБ) → что сделано
НА ПРОСЛУШКУ: файлы и что в них слушать
ЧЕСТНО: не слышу — проверено числами: <какими>; не проверено: <что>
```
