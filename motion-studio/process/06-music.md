# Этап 8 (часть 1) — музыка

Читать звукорежиссёру (`motion-sound`) и оркестратору, когда голос озвучен и приняты кадры
пилота. Вход — `film.json` и `probe.json` (границы глав и сцен), `voices.json` (поправки
голосов), ответ на В7 интервью. Выход — `music.json`, папка треков с манифестом лицензий,
`out/<film>/music.wav`, `mix.m4a`, `video-music.mp4`, файл треков для прослушки.

Музыка в эталонном ролике принималась по стандарту «библиотека → карта по главам → детерминированный
микс»; пользователь одобрил фоновую музыку с первого раза **после** смены пути: первый
путь — генерация во внешнем сервисе — дал слишком медленную мелодию и круг промптов впустую
(`../lessons.md` строка 12).

## Сначала библиотека с лицензией

1. **3–5 треков из библиотеки на прослушку, генерация — запасной путь.** Основание: отзыв:
   мелодии не понравились, пользователь попросил подобрать музыку в бесплатной медиатеке; библиотека даёт результат
   для выбора за один ход, генерация — вероятность. Треки подбираются по карте глав (ниже) и
   присылаются файлами с номерами, ответ — номером (`SKILL.md` золотое правило 10).
2. **Скачивание — только по явному «да»** пользователя: в вопросе имя файла, источник и размер
   (`SKILL.md` «Безопасность»). Без «да» — список ссылок, не файлы.
3. **У каждого трека строка манифеста**: файл, трек, автор или страница, URL, лицензия, нужна ли
   атрибуция. Образец — манифест эталонного ролика: пять треков Pixabay Content License, без
   обязательной атрибуции. Проверка: каждая дорожка микса есть в манифесте, лицензия из
   белого списка (поле `license` в `music.json`). Без строки трек в микс не идёт — это ворота этапа.
4. **Узнаваемые хиты не берём.** Сторонние руководства по монтажу советуют «музыка — хиты, никогда
   сток»; для корпоративного обучения это Content ID и права — не брать.

### Белый список лицензий

Статусы источников: «прочитано» — страницу открывали при сборе скила (2026-11-04); «найдено» — только
выдача поиска. Юридической консультацией это не является: сомнение — вопрос пользователю.

| Источник | Лицензия по странице | Решение | Статус |
|---|---|---|---|
| Pixabay Music (`https://pixabay.com/service/license-summary/`) | бесплатно, без атрибуции, можно изменять; нельзя продавать «как есть»; оговорка про права третьих лиц; про Content ID на странице нет | **брать**; так собраны треки эталонного ролика | прочитано |
| Kenney (`https://kenney.nl/support`) | CC0, коммерция, без атрибуции; про звук смотреть license-файл пака | **брать** после чтения файла пака | прочитано |
| Freesound (`https://freesound.org/help/faq/`) | у каждого файла своя | **только фильтр CC0**; CC BY — с титрами; CC BY-NC исключить: внутреннее обучение не очевидно «некоммерческое» | прочитано |
| Incompetech (`https://incompetech.com/music/royalty-free/licenses/`) | CC BY с обязательными титрами или платная лицензия без атрибуции | титры в манифест и в финальный кадр; платное — только по слову пользователя | прочитано |

| Sonniss GDC bundle | по вторичным источникам без атрибуции, запрет обучать ИИ на файлах; официальный текст не читали | **не брать, пока лицензия не прочитана** | найдено |
| Free Music Archive | не проверялось | не использовать | не проверялось |

### Запасной путь: генерация

Только если библиотека не дала трека под главу, и только по слову пользователя (внешний генератор —
чужой аккаунт и лимиты). Требования к промпту, проверенные на эталонном ролике: без вокала, без
ударных, без мелодии в диапазоне 300 Гц – 3 кГц (там живёт голос), ровная динамика, закольцовываемость.
Результат проходит тот же манифест: источник «сгенерировано», сервис, дата, промпт. Скил сам ничего не
генерирует и никуда не ходит.

## Карта по главам

Музыкальная карта делается **до** микса: глава → настроение → трек → точка смены. Смена трека — на
посадке полосы главы, не посреди мысли. Идея карты — общепринятая в монтаже; числа ниже наши.

| Поле | Что записывается | Правило |
|---|---|---|
| Глава | `id` из `project.json` | границы — из `probe.json`, не из головы |
| Настроение | 2–4 слова (спокойно, собранно, тепло) | под плотную речь — ровное, без «развития» |
| Трек | файл + лицензия | 3–5 треков на ролик; титульный и финальный могут отличаться |
| Смена | момент в долях главы или «полоса главы» | равномощный кроссфейд 2,5 с серединой на полосе |
| Короткий трек | по кругу | точка выхода — по корреляции волны (порог ≥ 0,5), иначе по огибающей атак; кроссфейд круга 3 с |

В эталонном ролике части шли по фазам, кроссфейд 2,5 с, круг короткого трека 3 с — те же числа
стоят умолчаниями `music.json` шаблона. Перед любой музыкальной «тишиной» (одно-два места на фильм
перед сильнейшей фразой) — решение режиссёра в раскадровке, а не микса.

## Уровни: наши числа

Все значения живут в `music.json` проекта и читаются и сборкой, и проверкой (`template/README.md`). Источник числа — замер эталонного ролика, не пересказ:

| Параметр | Значение | Основание |
|---|---|---|
| Уровень трека до огибающей | −20 LUFS | сборка эталонного ролика (`TRACK_LUFS`) |
| Музыка под репликой | на 20 дБ ниже речи; в любой реплике не менее 18 | сборка держала 20/18; прежнее условие проверки было мягче (≥ 15 дБ) — в шаблоне порог читается из `music.json` (`duck_db`) |
| Музыка в паузе между слайдами | на 6 дБ выше базы, если пауза ≥ 1,2 с | паузы внутри слайда 0,45 с в счёт не идут |
| Финал | затухание косинусом в ноль к концу фильма | |
| Итог | **−16 LUFS integrated** общей статической поправкой, **true peak ≤ −1 dBTP** | замер `loudnorm` / `ebur128`; запас: потолок ограничителя −1,6 dBFS на 4× — под пережатие AAC |
| Кодирование | AAC 192k, `-bitexact` | два прогона байт в байт |

Чужие числа — **не калибровано, только ориентир**: сторонние руководства по монтажу держат подложку
на −8…−9 дБ под речью и мастер около −14 и сами называют громкую музыку «самой частой жалобой» — для
плотной речи не берём. HeyGen советует «вырезать частоты голоса» в музыке вместо полного
приглушения, цель вроде «≈ 12 дБ под голосом»; ориентир стартовой точки из открытых обзоров — −12 дБ,
атака 30–80 мс, отпуск 250–700 мс, разница «голос − музыка» 15–20 LU — допущения для калибровки по
эталону, не стандарт. Цель −16 LUFS для веб-ролика подтверждена только вендорскими сводками; для
телевидения нужно −23 LUFS (EBU R128, прочитано: `https://tech.ebu.ch/publications/r128`).

## Пересборка без перерендера

Музыка и видео связаны только через `film.json` и `probe.json` на диске
(`template/README.md`). Поэтому:

- `"$PY" engine/audio/music.py <film> --mux` собирает `music.wav`, `mix.m4a` и **`video-music.mp4`, чей
  видеопоток бит в бит равен `video.mp4`** (условие микса M8 «видеопоток не перекодирован»). Сменили
  трек, уровень или карту — час рендера не нужен.
- Смена текста или озвучки сдвигает `film.json`: старый `video-music.mp4` **устарел**. Перед
  показом сверяется свежесть (время и хеш входов, `08-render-qa.md` «Свежесть артефактов»): в
  прошлом ролике `video-music.mp4` дважды оказывался старше `film.json` и один раз микс не собрался
  из-за занятого чужой сборкой файла (класс 19, `../checklists/defect-classes.md`).
- Сборку и проверку микса ведёт один сборщик (оркестратор) последовательно.

## Проверка микса

`engine/audio/check_mix.py` — условия микса эталонного ролика без тематических:
длины = фильм ± 1 кадр; музыка ниже речи в каждой реплике на порог `music.json`; true peak ≤ −1 dBTP;
−16 ± допуск LUFS; видеопоток бит в бит; **медианы громкости голосов в готовом миксе ≤ 0,5 дБ**
(мерится результат, не поправка); уровни и плотность эффектов; выше 8 кГц эффекты не громче музыки;
эффекты дошли до микса. Порчи и образцы — `--red`, `--samples`; полный `--red` на длинном ролике шёл
около 40 минут, поэтому есть фильтр по подстроке имени порчи.

## Классы дефектов

Таблица классов — одна, в [`checklists/defect-classes.md`](../checklists/defect-classes.md). Для музыки главные:
12 (громкость голосов: `check_audio.py` до микса, `check_mix.py` в миксе), 19 (устаревшие артефакты: `--mux`
после любого сдвига `film.json`), 20 (отложенное «потом»: музыка и эффекты — строками плана сразу).

## Ворота этапа (вместе с `07-sfx.md`)

`check_mix.py` зелёный; у каждого трека строка манифеста с лицензией из белого списка; файл треков
принят пользователем; `sfx-proba.mp3` принята; пересборка `--mux` выполнена после последней правки звука.
